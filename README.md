# MCX 知识库

按 3GPP Release 分开维护 MCX 规范知识，帮助读者理解职责、流程条件和容易混淆的边界。这里只提供整理后的解释与来源定位，不替代规范原文，也不保证完整实现。

Agent 从 [AGENTS.md](AGENTS.md) 和 [catalog.json](catalog.json) 按问题定位版本与主题，无需加载整库。

## 从哪里开始

- [Release 19](releases/rel-19/README.md)：首批公开候选，含位置报告及触发覆盖知识。
- [维护与验收](CONTRIBUTING.md)：来源、状态、公开检查和晋级要求。
- [迁移状态](migration/status.json)：明确已经迁入和仍未迁入的内容。

当前没有在本仓库重新验收并发布的正式知识版本。此前已有有限用途基线，但其完整内容和验收材料尚未迁入本仓库；首批候选不继承其验收结果。

后续推进顺序：Rel19 → Rel20 → Rel16 → Rel17 → Rel18。尚无正文的 Release 不建立空壳知识目录。

本仓库仅收录自撰摘要、可公开来源链接和核查记录，不托管标准全文、长篇原文摘录、私有文件链接或内部运行资料。源规范版权归相应权利人；未授予本仓库之外材料的转载许可。

# MCX 知识库

面向开发者与 Agent，按 3GPP Release 整理任务关键通信（MCX）的职责、流程、适用条件和规范依据。目标是让读者按问题取得足够上下文，不必加载整库或自行拼出遗漏条件。

## 阅读入口

- [Release 19](releases/rel-19/README.md)：MCPTT 呼叫信令、预建立媒体控制与话权、身份和安全、组文档与 LMR 互通，以及位置、网络策略、部分 MCVideo/MCData 业务要求与指定客户端、服务器协议路径。各主题覆盖范围和证据强度不同，详见版本入口。
- [Release 16](releases/rel-16/README.md)：MCPTT 同用户多客户端设置读取与观察、settings-only PUBLISH 发布及删除的有限职责、在网/离网呼叫、普通预安排组主动重入与服务器晚入、在网独立组紧急告警客户端本人发起/取消与通知、在网紧急预安排组客户端发起与本人取消、已有会话CF紧急升级与取消的有限职责、显式组归属与客户端话权，以及既有 Idle 状态的服务器请求与条件授予、单话权显式抢占与条件撤销的局部职责；MCData Stage 2 功能角色、Stage 3 私聊 SDS、私聊 SDS 会话信令/媒体与 HTTP FD，以及预安排组 standalone SDS 控制面客户端；MCVideo Stage 2 功能职责、普通按需私呼及预安排组呼客户端建立、普通私呼客户端传输/接收控制及普通预安排组服务器的传输请求、逐流接收许可与有限结束职责，以及普通离网组single参与者及实际仲裁者的局部媒体控制；普通在网预安排组显式抢占另覆盖满容量撤销、等待与实际 End 的有限职责。仅所列固定版本与局部职责，不代表完整组服务器分发、组媒体或端到端实现。

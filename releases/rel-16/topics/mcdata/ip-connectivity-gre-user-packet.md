# 在网一对一 MCData IP 互通：GRE 的 Protocol Type 为什么发出时置零、接收时忽略？

**发送端发出的 Protocol Type 非零，就不符合本版的发送格式。接收端实际收到这个包时，表注却要求它忽略该字段的值。** 这是同一包在发送和接收两端各自的规则。不能用接收规则解释发送端为何可以填非零，也不能只看非零就说接收方该拒收。[TS 24.582 V16.3.0，Release 16，Stage 3，§13.4 表 13.4-2 及 NOTE，印 46 页](https://www.etsi.org/deliver/etsi_ts/124500_124599/124582/16.03.00_60/ts_124582v160300p.pdf#page=47)

## 先定位记录：哪一段，谁收发，哪个包

这里只查本版**在网一对一 MCData IP 互通**的 GRE 用户数据。客户端在应用和隧道之间封装或解封装；参与功能在本侧客户端、控制功能之间中继；控制功能在两侧参与功能之间中继。用哪条规则，取决于本段哪个实体在发送或实际接收这一个包。应用接口上的普通 IP、其他段的记录、业务答复或建隧道成功，都不是本段这一个 GRE 包的收件证据。通用 GRE 和组 IP 互通不套本页。[§4.1.4，印 11 页](https://www.etsi.org/deliver/etsi_ts/124500_124599/124582/16.03.00_60/ts_124582v160300p.pdf#page=12)；[§13.1.1–.2，印 44 页](https://www.etsi.org/deliver/etsi_ts/124500_124599/124582/16.03.00_60/ts_124582v160300p.pdf#page=45)；[§13.1.3、§13.2–.3，印 45 页](https://www.etsi.org/deliver/etsi_ts/124500_124599/124582/16.03.00_60/ts_124582v160300p.pdf#page=46)

## 发送：八字节 GRE 头，后面放一个用户 IP 包

| 位置（从 GRE 头首字节算起） | 本版编码 |
| --- | --- |
| 字节 1 | C=0、K=1、S=0；其余相应位为 Reserved0。 |
| 字节 2 | 图中标出 Reserved0 和 Ver；字段定义见表引的 RFC。 |
| 字节 3–4 | Protocol Type，置零。 |
| 字节 5–8 | Key，填这个 IP 包关联的 IP 互通会话标识。 |
| 字节 9 至末尾 | Payload packet，放**一个**用户 IP 包。 |

看到发出的 Type 为零，只能确认这一项编码。要确认整份封装，还须核对其他头字段和载荷。抓包只截到 Type，也不等于实际发出的包缺了剩余字段。[§13.4 图 13.4-1、表 13.4-1、图 13.4-2，印 45 页](https://www.etsi.org/deliver/etsi_ts/124500_124599/124582/16.03.00_60/ts_124582v160300p.pdf#page=46)；[表 13.4-2，印 46 页](https://www.etsi.org/deliver/etsi_ts/124500_124599/124582/16.03.00_60/ts_124582v160300p.pdf#page=47)

## 接收：忽略的是一个字段的值

对本段实际收到的 GRE 用户数据，表 13.4-2 的 **NOTE** 要求接收实体忽略 Protocol Type 的值。值为零或非零，不改变这一点；不要用这个字段决定载荷的 IP 类型。已确认本段实收、但抓包只保留了 Type，仍能用这条字段规则，余下格式不能从这份记录核实。表注未规定怎样判其他头字段、载荷或会话关联，也不证明包已接受、已解封装或已交应用。只有发送侧或另一段的日志时，只能说明规范对接收端写了什么，不能确认本段实际发生的处理。[表 13.4-2 的 NOTE，印 46 页](https://www.etsi.org/deliver/etsi_ts/124500_124599/124582/16.03.00_60/ts_124582v160300p.pdf#page=47)

**Key 用来找会话。** 本版将它填为这个 IP 包所关联的会话标识；客户端怎样设置标识由实现决定。同会话的不同包可以有同一个 Key。Key 不是密码密钥，也不能单独用来证明哪个应用收到哪一个包，或认定两段隧道的标识值必相同。[§13.1.2，印 44 页](https://www.etsi.org/deliver/etsi_ts/124500_124599/124582/16.03.00_60/ts_124582v160300p.pdf#page=45)；[§13.1.3、§13.2，印 45 页](https://www.etsi.org/deliver/etsi_ts/124500_124599/124582/16.03.00_60/ts_124582v160300p.pdf#page=46)；[表 13.4-2，印 46 页](https://www.etsi.org/deliver/etsi_ts/124500_124599/124582/16.03.00_60/ts_124582v160300p.pdf#page=47)

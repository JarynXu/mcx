# MCData 消息存储：给存档加标记和永久删除存档，各改变什么？

一条消息或一个文件可连同元数据保存在用户的 MCData 消息存储区，成为一个带标识的对象。给对象加上“已标记”（flagged），更新的是它的**元数据**，不是替换消息正文或文件内容。**删除成功**则表示消息存储已永久移除指定对象，不只是把它标成“已删除”。[3GPP TS 23.282 V16.8.0，Release 16，Stage 2，§7.13，印刷页 140](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=141)；[§7.13.3.4.1，页 149](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=150)；[图 7.13.3.5.2-1，步骤 2，页 151](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=152)。

两种操作都要求消息存储客户端与 MCData 消息存储之间已成功完成认证和授权，客户端也已知道对象标识。用户只能访问本人的存储区。**删除还要求该用户有权删除这个对象**；能访问账户、知道标识，甚至先前成功加过标记，都不能代替这项权限。[§7.13.1，页 140](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=141)；[§§7.13.3.4.2、7.13.3.5.2 的前提，页 150](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=151)。

| 操作 | 客户端发给消息存储的请求：哪些项必填？ | 消息存储如何处理？ |
| --- | --- | --- |
| 更新 | 用户的 MCData ID、对象标识、要更新的元数据。 | 按对象标识找到存档，按请求更新元数据，再向该客户端报告结果。 |
| 删除 | 用户的 MCData ID、对象标识。 | 按对象标识找到存档，将它从消息存储永久移除，再向该客户端报告结果。 |

请求中的 MCData ID 标识**用户**，不是对象标识。两种响应都列两项必填：标识该用户**存储区**的 MCData ID，以及本次操作的结果（成功或失败）。响应表不列对象标识或对象内容。只看到请求、只看到响应名称，或者读到失败结果，都不能当作已成功改动存档的证据。[更新：表 7.13.3.1.5-1、7.13.3.1.6-1，页 142](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=143)；[删除：表 7.13.3.1.7-1、7.13.3.1.8-1，页 143](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=144)；[更新流程：图 7.13.3.4.2-1，步骤 1–2，页 150](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=151)；[删除流程：图 7.13.3.5.2-1，步骤 1–2，页 151](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=152)。

**原下载链接还能用吗？** 单凭存档删除成功，不能判断。按对象标识删除的是本人消息存储里的对象；按文件 URL 从**内容服务器**撤下已上传文件，是[另一项操作](http-file-removal.md)。这份存档删除响应也不证明另一账户的对象或另一台设备上已有的本地副本已被删除。要判断终端取得了哪些变更，另看[消息存储同步](message-store-sync.md)；若尚不知道要操作哪个对象，可先查[按标识取回与按条件搜索](stored-object-lookup.md)，已知对象标识则不需要先搜索。

# MCData：消息和文件该用哪一个会话 ID？

甲和乙同时在清点器材、安排车辆。甲在“清点器材”里发过一条短数据消息（SDS），乙要用文件分发（FD）回传器材清单。**清单沿用“清点器材”的会话 ID**；如果乙发的是车辆安排，就用“安排车辆”的 ID。如果车辆会话还不存在，就为它生成新 ID。两个人没换，谈的活动却可以分开；从短消息换成文件，本身也不必另开会话。

会话 ID（conversation identifier）是**全局唯一**的，标识一系列相关的 MCData 事务。这是本规范的术语定义，适用于在网、离网、一对一和组会话。[TS 23.282 V16.8.0，§3.1，印刷页 14](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=15)。

MCData 用会话（conversation）把一次活动的相关传输呈现为一条讨论线索。其中可以只有 SDS、只有 FD，也可以两者都有。用于会话管理时，每笔 SDS 或 FD 事务都须带会话管理服务指示和会话 ID。参与用户集合不同，须当作不同会话；参与者相同而会话 ID 不同，也须分开。不能仅凭相同的组 ID 或收发双方判断两笔传输属于同一会话。[3GPP TS 23.282 V16.8.0，Rel-16 Stage 2，§5.7，印刷页 19](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=20)；[§7.8.1，印刷页 134](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=135)。

**四种场景都按同一办法选 ID：** 发起新会话时生成新 ID；继续已有会话时，使用那一次会话的 ID；同一对用户或同一组并行开展多个会话时，每个会话用不同的 ID。后续运行的是对应的一对一或组 SDS、FD，或两者的组合。选择办法相同，启动程序的前提不同：

| 场景 | 启动该程序的前提 | 程序依据 |
| --- | --- | --- |
| 在网一对一 | 两端用户都已注册接收 MCData 服务。 | [§7.8.2.2.1，图及步骤 1–2，印刷页 134–135](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=135) |
| 在网组 | 参与用户都已注册接收 MCData 服务，属于同一 MCData 组，且已归属到 MCData 服务。 | [§7.8.2.3.1，图及步骤 1–2，印刷页 135](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=136) |
| 离网一对一 | 两个客户端同属一个 ProSe 发现组，都支持 ProSe 一对一直通；发起端已经通过 ProSe 发现过程，在近处发现了与目标用户关联的客户端。 | [§7.8.3.1.1，图及步骤 1–2，印刷页 135–136](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=136) |
| 离网组 | 各客户端是同一 MCData 组的成员；发起端已预配置该组的 ProSe 直通通信信息，以及该 MCData 组到 ProSe 二层组 ID 的映射。 | [§7.8.3.2.1，图及步骤 1–2，印刷页 136–137](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=137) |

在网组的步骤 1 写的是 *unique*，其余三个步骤 1 写的是 *universally unique*。在网组仍使用 §3.1 定义的全局唯一会话 ID；不能因为本步骤少一个定语，就让两个不同组的新会话复用同一个值。离网组另有预配置的 ProSe 二层组 ID，它标识组，不能替代会话 ID。

四个程序都允许用户在会话内**第一笔 MCData 事务发起后**查看该会话，无须等第一笔传输完成。会话 ID 能说明一条消息或一个文件归入哪次活动；能看到会话，并不能证明对方已收到某条消息、已下载文件，或全体组员已收到内容。要查本人存储区中已经保存的内容，见[按对象 ID 取回或按条件搜索](stored-object-lookup.md)。

# MCData 消息存储：不指定文件夹，从哪里开始列目录？

**不指定目标，就从本人消息存储账户的根目录开始；指定某个文件夹，就查看以它为起点的文件夹层次。** 例如，“值班”和“培训”同在账户根下，“值班”里还有“交接”和一份日志。指定“值班”时，“交接”在查询范围内，“培训”不在。看到“交接”不能证明客户端也取回了日志正文。[3GPP TS 23.282 V16.8.0，Release 16，Stage 2，§7.13.3.15.1，印刷页 160](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=161)；[§7.13.3.15.2 步骤 1–3，页 161](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=162)。

这项查询针对用户本人已有的 MCData 消息存储账户。消息存储客户端与 MCData 消息存储之间须已成功完成认证和授权；账户按文件夹分层，这项操作才有意义。规范没有据此规定无层次账户一定返回什么错误。[§7.13.3.15.1–2，总述和流程前提，页 160](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=161)。

客户端发给消息存储的列目录请求中，**用户的 MCData ID 必填，目标文件夹标识可选**。指定目标时，用文件夹标识，不用用户 ID 代替。步骤 1 也写的是标识；步骤 2 在说明省略目标时却用了“名称”一词。信息表没有列单独的名称字段，不能把显示名称当成标识，也不能要求同时传名称和标识。[表 7.13.3.1.27-1，页 147](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=148)；[§7.13.3.15.2 步骤 1–2，页 161](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=162)。

消息存储根据目标生成视图，再向客户端返回列目录响应。**响应表列出的必填项是用户的 MCData ID 和列目录的结果（Result）。** 总述和步骤 2 说的是目标文件夹及其全部子文件夹；响应表的注释说，有标识时返回该文件夹的子文件夹，无标识时从账户根返回文件夹。这能确定查询从哪个分支开始，却没有规定响应如何逐层列出更深的目录。比如，已知“交接”里还有“早班”，就能判断“早班”属于“值班”这个分支；如果没看到本次结果的具体条目，不能断定“早班”也被逐项列了出来。这既不是“只返回直接子目录”的规定，也不是一次响应必定递归展开全部后代的保证。目标自身是否另列一条、各项顺序以及是否用嵌套 JSON 表示，这些条款也没有规定。[表 7.13.3.1.28-1 及注，页 147](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=148)；[§7.13.3.15.2 步骤 2–3，页 161](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=162)。

如果要打开那份日志，已知对象标识可[按对象标识取回；不知道标识可按条件搜索](stored-object-lookup.md)。列目录响应的必填项中没有存储对象；仅凭它也不能认定文件夹刚被[新建或删除](stored-folder-create-delete.md)，或被[复制或移动](stored-folder-copy-move.md)。这些是不同的操作，不是列目录之后必走的步骤。[列目录响应表，页 147](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=148)；[对象取回和搜索，§§7.13.3.2–3，页 148–149](https://www.etsi.org/deliver/etsi_ts/123200_123299/123282/16.08.00_60/ts_123282v160800p.pdf#page=149)。

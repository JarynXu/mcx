# 离网时收集哪些审计元数据，恢复在网后能取回什么？

**§7.14 要求收集活动元数据，未规定收集通话录音或视频本身。** [R-7.14-001，印刷页 57](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=58) 要求离网 MCX 业务能从处于离网模式的终端收集三类活动的元数据：组通信、私通信，以及更改组设置等非通信活动。对于通信，发送参与者和接收参与者（一人或多人）都须有元数据记录。发起用户的 MCX 业务用户 ID、业务组 ID 是条文举的例子，不是每类活动都必须填的字段。

**恢复在网后，记录从哪里来？** [R-7.14-002，印刷页 57](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=58) 要求 MCX 业务能从那台终端取回它在离网时已收集的通信和非通信活动元数据。触发条件是恢复在网运行，不只是重新有信号：[§7.1，印刷页 50](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=51) 也把有覆盖但选择直通路径使用 MCX 业务的情形列为离网。条款要求提供取回机制，未要求终端主动上传，也没给出取回完成的期限。

以上是 3GPP TS 22.280 V16.8.0（Release 16，Stage 1）的离网审计要求。[表 A.1（MCPTT），印刷页 71](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=72)、[表 B.1（MCVideo），印刷页 82](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=83)、[表 C.1（MCData），印刷页 93](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=94) 均在 §7.14 行列出 -001、-002。在网时能否记录传输内容，见[在网组通信和私通信的记录要求](onnetwork-communication-recording-and-audit.md)；在网时要记哪些非通信活动，见[在网活动审计](onnetwork-activity-audit.md)。这两处的字段清单不是离网日志格式。

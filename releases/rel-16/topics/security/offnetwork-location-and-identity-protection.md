# 离网终端交换位置和身份信息时，哪些信息要保密，要认证的是谁？

离网时，甲的 MCX 终端向其他 MCX 终端传送位置和身份信息，或从其他 MCX 终端接收这些信息，甲都必须能保护其机密性。[TS 22.280 V16.8.0 §7.9，R-7.9-001，印刷页 55](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=56) 涵盖**位置和身份**两类信息；只检查发出的坐标，会漏掉身份信息和接收方向。

对于携带位置和身份信息的消息，离网 MCX 终端还必须能**认证发送这条消息的一方**。见 [R-7.9-002，印刷页 55](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=56)。仅凭内容受到保密保护，不能认定接收端已经认证了发送者；即使认证了发送者，也不能据此断定消息中的位置准确或仍是当前位置。

这是 Release 16 的 Stage 1 离网要求，范围见[第 7 章标题，印刷页 50](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=51)。规范性[表 A.1（MCPTT），印刷页 70](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=71)、[表 B.1（MCVideo），印刷页 81](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=82)和[表 C.1（MCData），印刷页 92](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=93) 的 §7.9 行都列出 R-7.9-001 和 R-7.9-002。

§7.9 没有规定算法、密钥分发方式或认证报文，也没有规定每条离网消息必须携带哪些字段。要查终端何时能向别的终端发送本机位置，见[离网位置发送与终端间距离](../location/offnetwork-ue-location-and-distance.md)。[在网终端要求认证 MCX 业务](service-authentication-requirements.md)时，被认证的是业务，不是这里的消息发送者。

# 应用层要保护哪些流量？媒体经过网络转发，还要支持端到端安全吗？

就算无线链路已经加密，也还要问：**MCX 业务在应用层能否保护所有用户流量和信令的机密性和完整性？** 这是 R-5.12-001 的要求，只有链路层证据不够。该条要求业务提供支持这两种保护的手段，没有规定所有信令都要采用端到端保护。[§5.12，印刷页 25](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=26)

两台 MCX 终端互传媒体，看的还有另两条要求：

- **保护谁之间的什么流量？** R-5.12-009 要求业务提供手段，支持这两台终端之间传输的**全部媒体流量**的端到端安全。它说的是传输中的媒体，不是已保存在终端上的媒体。
- **经过转发，或者终端不在网络覆盖内，要求会改变吗？** R-5.12-010 要求覆盖内和覆盖外都支持端到端安全；流量直接传送还是经过网络基础设施，不影响这一要求。经网络转发不等于保护的端点可以止于转发节点，也不表示任何时候两种路径都可用。[§5.12，印刷页 25](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=26)

这里规定的是业务须支持什么，不能据此判定某次通信实际启用了哪种算法或哪组密钥。本主题属于[TS 22.280 V16.8.0（Release 16，Stage 1）第 5 章的在网、离网共同要求，印刷页 12](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=13)。这些编号均见规范性[表 A.1（MCPTT，印刷页 64）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=65)、[表 B.1（MCVideo，印刷页 75）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=76)和[表 C.1（MCData，印刷页 86）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=87)。

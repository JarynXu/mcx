# 在网 MCX 发送请求被拒、入队或撤回时，谁须收到通知？

**通信入队、被拒，或出队后已经开始，业务都须通知提出请求的 MCX 参与者；是否再通知一名或多名获授权用户，由业务决定。** 另有一条要求：某用户的请求从队列中移除时，须通知请求所属的用户。仅有“从队列中移除”的记录，不能据此判定通信已经开始。[TS 22.280 V16.8.0 §6.19.1.1，R-6.19.1.1-003、-006，印刷页 50](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=51)。

## 发出请求就必须排队吗？

不必。业务必须能让**任何 MCX 发送请求**排队，也必须能拒绝发送请求并**给出原因指示**。有这两种手段，不等于每个请求都要先排队，也没有指定拒绝消息或原因码。[R-6.19.1.1-001、-002，印刷页 50](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=51)。

[§6.19.1 的无编号说明，印刷页 50](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=51)说明了请求到达和排队后的处理：相互竞争的请求通常携带优先级信息，供分配传输资源时仲裁；请求到达时即获准、被拒或入队。排队条件解除后通常会获准，但请求也可能因多种原因被自动丢弃，或由获授权的用户取消，此人通常是请求发起者。被拒后可以由用户手动再请求，也可以自动再请求。这段没有规定排队一定获准、固定等待时长或一律自动重试。关于**按优先级排队与保留**的另一项要求，见 [§6.8.1 的排队与抢占](../bearers/onnetwork-service-preemption.md)。

## 谁能把请求移出队列？

| 情形 | 业务必须支持什么 |
| --- | --- |
| 用户自撤 | 让 MCX 用户从队列中移除自己的发送请求（R-6.19.1.1-004）。 |
| 用户代撤 | 让**获授权**的用户从队列中移除另一用户的发送请求（R-6.19.1.1-005）。 |
| 自动移除 | 让 **MCX 管理员**配置一个或多个业务参数，用于从任一 MCX 请求队列自动移除发送请求。定时器是例子，未规定必须用它或设多少秒（R-6.19.1.1-007）。 |

[§6.19.1.1，-004 至 -007，印刷页 50](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=51)。例如，乙获准替甲撤回排队请求。乙发起代撤时，还不能判定请求已经移除。若甲的请求已移除，就须通知甲；只通知乙不能代替通知甲。这也不等于撤销别人的发送权，或结束整场通信。该节没有要求一定用两条独立消息来区分“移除”与“出队后开传”。

这是 Release 16、Stage 1 的[在网要求，印刷页 29](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=30)。§6.19 是标题，§6.19.1 是业务说明。三个规范性适用表都把这两行标为 NA，在其下 **§6.19.1.1** 列出全部七项要求。MCPTT 的 [A.1，-001 至 -006，印刷页 69](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=70)、[续页 -007，印刷页 70](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=71)；MCVideo 的 [B.1，印刷页 80](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=81) 和 MCData 的 [C.1，印刷页 91](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=92) 各在同一页列全。

# 终端在一个组里收发时，还能接收哪些组？Nc4 和 Nc5 各数什么？

一台 MCX 终端正在甲组发送时，业务须允许它同时接收其他组的通信；它在甲组接收时也一样。甲组可以是收或发，其他组在这项要求里都是**收**。这条没有说终端须能向多个组同时发送，也没有说用户此刻听到或看到的是哪个组。[R-5.4.2-001，印刷页 15](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=16)。

## 同时接收几场组通信：按终端数，还是按用户数？

| 变量 | 计数对象 | 规范要求 |
| --- | --- | --- |
| Nc4 | 一台 MCX 终端（UE） | 业务须提供机制，配置这台终端能同时接收的组通信数量。[R-5.4.2-002，印刷页 15](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=16) |
| Nc5 | 一名 MCX 用户 | 业务须提供机制，配置这名用户能同时接收的组通信数量。[R-5.4.2-003，印刷页 15](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=16) |

两项配置都由 MCX 业务管理员和/或获授权用户授权。计的是**同时接收的组通信**，不是已经归属的组，也不是用户名下的终端。[信息性表 E.1 的 Nc4、Nc5 两行，印刷页 96](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=97)给出变量含义，没有给固定数值；本节也没有规定一人有多台终端时如何合计，或两个配置如何取舍。

**多个组都有发送者。** 终端接收多个有发送者的业务组时，业务须向该终端提供多个 **MCX 业务用户 ID**。条文没有换成组 ID，也没有要求向用户显示这些 ID，或规定每组与哪个 ID 一一对应。[R-5.4.2-005，印刷页 16](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=17)。

**一边在网，一边离网。** 业务须允许一台**获授权的终端**同时接收在网组通信和离网组通信。这里不要求终端在两侧同时发送，也没有让它把一侧的内容转发给另一侧。[R-5.4.2-006，印刷页 16](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=17)。

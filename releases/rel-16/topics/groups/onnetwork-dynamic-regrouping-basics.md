# 在网动态重组：谁能管理，临时组何时拆除？

**临时组还在，不等于组内仍有人通话。** 这里讨论组重组（Group Regroup）或用户重组（User Regroup）形成的临时组，以及谁能决定怎样管理它。依据是 3GPP TS 22.280 V16.8.0（Release 16）在网动态重组的 Stage 1 要求。[第 6 章，印刷页 29](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=30)；[§6.6.1，印刷页 34（PDF 第 35 页）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=35)。

| 要解决的问题 | §6.6.1 的要求 |
| --- | --- |
| 谁能管理两类重组 | 已获授权的 MCX 用户须能管理组重组和用户重组操作。不能仅凭调度员等角色名称认定某人已获授权。[R-6.6.1-001，印刷页 34](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=35)。 |
| 临时组保留到什么时候 | 两类操作所形成的临时组须持续存在，直到已获授权的 MCX 用户拆除它。[R-6.6.1-002，印刷页 34](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=35)。 |
| 谁定临时组优先级 | 由临时组的创建者设定，但不得超出 MCX 业务管理员设定的范围。本条不规定具体值，也不把它当成本次传输或话权结果。[R-6.6.1-003，印刷页 34](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=35)。 |
| 谁能授予或撤销重组授权 | MCX 业务须使业务管理员能授予、也能撤销 MCX 用户执行动态重组操作的授权。撤销授权本身不是拆组。[R-6.6.1-004，印刷页 34](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=35)。 |
| 谁能设临时组是否加密 | MCX 业务须使业务管理员能配置是否加密。这里规定的是设置能力，不是统一默认值、密钥流程或已经加密的凭据。[R-6.6.1-005，印刷页 34](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=35)。 |

例如，组重组已建成临时组 T，T 上的一场组呼结束了。如果没有获授权的用户拆除 T，-002 仍要求这个组存在。不能把组呼结束、参与者离开或某个通话定时器到期当成拆组证据。

## 按普通组处理，不表示它能成为另一次组重组的输入

**两类重组形成的临时组都须按其他 MCX 业务组对待。** -006 单列的例外是：这项普通组待遇不包括把**组重组形成的临时组**纳入**另一次组重组**的能力。不能从这个例外的措辞反推用户重组形成的临时组可以纳入组重组。另条 §6.6.2.2-011 从组重组的输入说得更直接：业务须阻止已获授权的 MCX 用户把临时组纳入组重组，条文本身没有按临时组的形成方式缩小这个限制。这里只用 -011 界定边界，不展开组重组的其他要求。[R-6.6.1-006，印刷页 34](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=35)；[R-6.6.2.2-011，印刷页 35（PDF 第 36 页）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=36)。

**适用业务：** 本版表 A.1（MCPTT）、B.1（MCVideo）和 C.1（MCData）各在 §6.6.1 行列出上述六项。§6.6 总标题的 NA 不覆盖这一细分行。[MCPTT，表 A.1，印刷页 66](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=67)；[MCVideo，表 B.1，印刷页 77](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=78)；[MCData，表 C.1，印刷页 88](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=89)。

# 在网业务组能设多少名成员？移除、禁用和重新启用有什么不同？

管理员限制的是**一个组的成员总数**。人数上限和组状态是两回事：移除组会把组从系统移除，禁用组改变的是组的启用状态。

| 管理员想做什么 | MCX 业务须支持什么 |
| --- | --- |
| 限制组员人数 | 让 MCX 业务管理员能限制**某一个组的成员总数**（Nc6）。数的是这个组的成员，不是当前已归属人数、在场接收人数或某次组通信的参与人数。[R-6.1-001，印刷页 29](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=30)；[信息性表 E.1，Nc6 行，印刷页 96](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=97)只解释变量，没有给出统一数值。 |
| 从系统移除组 | 让管理员能从 MCX 业务系统移除**组本身**，而非仅移出某一名成员。条款没有规定移除后能否还原或如何处置进行中的通信。[R-6.1-002，印刷页 29](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=30)。 |
| 改变组的启用状态 | 让管理员能禁用业务组，也能将其重新启用。重新启用指改变组状态，不是恢复一个已经从系统移除的组。[R-6.1-003，印刷页 29](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=30)。 |

如果问题是“组重新启用后，某个用户就又归属这个组了吗”，还要看用户操作。[§6.13.4，R-6.13.4-004，印刷页 45](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=46) 只允许用户归属或选定**已启用的组**。启用是必要条件，不能证明某个用户获准、已经归属或已经选定；也不能据此推断此前禁用时如何处理原有归属。见[组的访问条件](../security/access-eligibility-requirements.md)。这里禁用的是组，不是暂停某个用户或终端的整个业务访问。若问这个组眼下有没有接收者，见[在场接收与组状态](onnetwork-group-status-information.md)；管理变更何时起作用，见[管理员活动与变更生效](../identity/onnetwork-administrator-activities-and-change-timing.md)。

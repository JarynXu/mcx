# 离网通信中，后来加入的人也在发送者身份和位置的接收范围内吗？

**包括中途加入的人。** 离网时，发送端须能把下面两类信息发给这次通信中的所有其他用户，包括后来才加入通信的离网终端。这里认的是正在发送的那台终端及其用户，不限定为语音通话。

| 离网终端须能发送什么 | 条款怎样限定 |
| --- | --- |
| 发送者的身份、组和组织信息 | MCX 业务用户 ID、一个或多个别名、离网 MCX 业务组，以及**可获得时**该发送用户的任务关键组织名称。见 [R-7.2-004，印刷页 52](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=53)。 |
| 发送者的位置 | 须能发送该发送者的位置信息，接收对象与上一项相同。组织名称的“可获得时”不是这项要求的条件。见 [R-7.2-005，印刷页 52](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=53)。 |

例如，新加入通信的乙，也在甲的终端须能向其发送这些信息的范围内。但两条要求规定的都是**终端的发送能力**：它们并不说明乙已收到、屏幕已显示，或甲必须向乙重发过去的每次位置。[§7.1 概述，印刷页 52](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=53) 提到业务组 ID 和组别名；-004 的编号正文写的是“离网 MCX 业务组”，没有分别列出这两个字段，也没有规定消息编码。若甲走的是在网路径，另查[在网发送者和所选组的标识](onnetwork-id-and-alias-management.md)或[在网位置提供与报告控制](../location/onnetwork-location-sharing-and-report-control.md)。

依据：3GPP TS 22.280 V16.8.0，Release 16，Stage 1。规范性表 [A.1（MCPTT，印刷页 70）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=71)、[B.1（MCVideo，印刷页 81）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=82)、[C.1（MCData，印刷页 92）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=93) 均列出这两项。

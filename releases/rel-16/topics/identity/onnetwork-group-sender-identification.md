# 在网组通信中，接收终端应获哪些身份信息？用户应看到哪些别名？

**给接收终端提供身份信息，与向用户呈现易读别名，是两项要求。** 以下只读 3GPP TS 22.280 V16.8.0（Release 16）在网组通信的 Stage 1 条款。[第 6 章，印刷页 29](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=30)；[§6.4 的组通信范围，印刷页 30](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=31)；[§6.4.3，印刷页 31（PDF 第 32 页）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=32)。

## 向接收终端提供发送参与者和组的标识

**发送参与者的身份未受限时，** 业务须向接收侧 MCX 终端提供 MCX 业务用户 ID 及其关联别名、MCX 业务组 ID 及组别名。该发送参与者的任务关键组织名称标识**可获得时**，也须提供。可获得这一条件只限定组织名称标识，不限定前面的用户和组标识。[R-6.4.3-001，印刷页 31](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=32)。

例如，业务用户别名和组别名都可用，但发送参与者的任务关键组织名称标识无法获得。若其身份未受限，业务仍须向接收端提供用户和组的 ID、别名，不能仅凭缺组织名称就认定发送参与者身份受限。身份受限是这一提供义务的例外；该条没有规定怎样判定限制、应遮蔽哪些字段、或哪些信息在受限时仍可披露。业务须提供也不证明某台终端已实际收到这些信息。

## 向用户呈现两类易读别名

业务须向用户呈现**可供人阅读的用户别名和组别名**，即 MCX 业务用户 ID 的别名和 MCX 业务组的别名，两类的最小长度都为 `Nc3`。信息性表 E.1 把 `Nc3` 列作字母数字标识（Alias ID）的最小长度变量。这里没有给定数值、最大长度、字符计数方式、编码或界面样式，也不把每个原始业务 ID 当成易读别名。R-6.4.3-002 没有重复 -001 的身份限制条件；不能把 -001 的条件一概套给它，也不能拿 -002 当作披露受限身份的授权。[R-6.4.3-002，印刷页 31](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=32)；[表 E.1 的 Nc3 行，印刷页 96](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=97)。

**适用业务：** 本版表 A.1、B.1、C.1 对在网 MCPTT、MCVideo 和 MCData 都列出这两项。这里只规定业务要求，不指定 SIP 头、XML 字段或其他线上承载。[MCPTT，表 A.1，印刷页 65](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=66)；[MCVideo，表 B.1，印刷页 76](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=77)；[MCData，表 C.1，印刷页 87](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=88)。

要区分认证、业务和路由身份，查[跨业务用户标识](cross-service-user-mapping.md)；[普通 MCPTT 私呼的主叫功能别名](../calls/private-caller-alias-forwarding.md)是另一项信令规则，不能直接当成这里的用户 ID 别名。[MCPTT 会话 GRUU 的敏感身份限制](../calls/session-gruu-sensitive-identity.md)也只按它自己的适用条件判断，不由这里决定会话 URI 的内容。

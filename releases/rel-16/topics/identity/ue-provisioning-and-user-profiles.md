# 用户至少关联几份配置档？谁管用户档，谁能配置终端？

用户换了一台终端，要分开查两件事：**业务给这个用户关联了什么档，终端能支持什么档**。MCX 业务用户配置档是一组与用户相关的信息，供用户以某个角色和/或从某台终端使用业务。[§3.1 定义，印刷页 10](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=11)。

| 查什么 | 标准要求 |
| --- | --- |
| 按用户查：是否必须有档？ | MCX 业务须确保每一位 MCX 用户至少关联一份用户档，记录该用户的信息，包括其对 MCX 业务的权限和特权。[R-5.9-001，印刷页 21](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=22)。 |
| 按设备查：终端须支持几份？ | MCX 终端须支持一份或多份 MCX 业务用户配置档。本条没有规定同时启用几份，也不能证明某份档已装到当前终端。[R-5.8-001，印刷页 21](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=22)。 |

例如，甲关联了两份用户档，不能因此认定车载终端已经装了两份、甲正在同时使用两份。规范在 R-5.9-001 后的注中举例：档中可以记录业务用户 ID、所属业务组、参与者类型、所属管辖方，以及能否发起或接收私通信。这是信息示例，不是这条要求规定的完整必填字段表。

**谁管用户档？** 业务须让 MCX 业务管理员能管理其权限范围内用户的档。这个范围指管理员管辖哪些用户，不是允许他管理系统中每个人的档。[R-5.9-002，印刷页 21](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=22)。要查在网时能否改一份正在使用的档、谁指定何时安装，见[在网用户配置档管理](user-profile-management-requirements.md)。

**谁能配置终端？** MCX 业务须提供机制，让 MCX 业务管理员和/或获授权的 MCX 用户能为 MCX 终端作配置（MCX UE Provisioning）。条文没有要求两人共同操作，也没有把这项能力给所有普通用户。有权配置一台设备不能据此取得管理他人用户档的权限。[R-5.8-002，印刷页 21](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=22)。实际拿到的是设备配置还是人的档，见[终端配置获取](ue-configuration-retrieval.md)；要判断某个客户端改用了哪份档，见[用户档切换](user-profile-switch.md)。

这四项属于 TS 22.280 V16.8.0（Release 16，Stage 1）[在网与离网共用的第 5 章，印刷页 12](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=13)。MCPTT 表 A.1（[印刷页 64](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=65)）和 MCVideo 表 B.1（[印刷页 75](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=76)）各列这四项；MCData 表 C.1 的 §5.8 两项在[印刷页 85](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=86)，§5.9 两项在[印刷页 86](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=87)。

# 主系统登录：SIP 已注册，能说明用户通过了哪项认证、获准了哪些 MC 业务？

只看到 SIP 注册成功，可以确认终端已在 SIP 核心完成注册。要确认 **MC 用户是谁**，看这名用户的身份认证结果；要确认**他能用哪项 MC 业务**，看对应业务的授权结果。三件事可以出现在同一段登录记录里，却不是同一个结果。这里讲的是 3GPP TS 23.280 V16.7.0（Rel-16，Stage 2）的主 MC 系统（Primary MC system）。图 10.6.1-1 给出单域示例，是高层流程，不是逐包时序。[§10.6.1 标题和首注，印 114](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=115)；[图 10.6.1-1、步骤 1–3 和末注，印 115](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=116)。

| 查哪件事 | 单域示例怎么做 | 哪一步还不能据此确认 |
| --- | --- | --- |
| MC 用户身份认证（步骤 1） | 身份管理客户端发起过程，用户提供凭据，身份管理服务器核验；图中用户通过认证并取得访问令牌。 | 只见提交凭据，不等于核验成功；即使已取得令牌，也不能把任一项业务记为已获准。 |
| SIP 层认证与注册（步骤 2、3） | 信令用户代理先与 SIP 核心建立安全连接，供 SIP 层认证和注册使用，再完成 SIP 层注册。本步还可包括向 MC 业务服务器进行的第三方注册。 | 建好连接不等于已注册。第三方注册是可选项；没有它不推翻已经完成的 SIP 注册，看到它也不能代替业务授权结果。 |
| 用户的某项 MC 业务授权（末注） | MC 业务客户端利用上述过程的结果，为该用户办理对应业务的授权。 | 一项业务获准，不表示同一用户的其他业务也已获准。 |

[图 10.6.1-1 及步骤 1–3、末注，印 115](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=116)。步骤 1 的文字说身份管理客户端开始用户授权过程；图中这一步取得的是用户认证结果和访问令牌，并非各项业务都已授权。

**先注册再认证，顺序就错了吗？** 不一定。步骤 1 明说，用户认证可在步骤 3 的 SIP 注册之前或之后。图前还列了另一种做法：在 SIP 注册阶段内认证用户。这不表示每次普通 SIP 注册都包含 MC 用户认证，也没有指定认证必须挤进哪一条 SIP 报文。认证还可独立于 SIP 注册阶段；SIP 核心在 MC 业务服务器所属域之外是一个例子，不是独立认证的必要条件，也不能只凭分域就断定某次认证的时间。要还原一次登录，拿同一用户的身份管理记录与本次 SIP 注册的记录对时，不能照图号补时间戳。[§10.6.1 图前两段与步骤 1，印 115](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=116)。

**多开一个业务，要不要再验一次人？** 在提供多项 MC 业务的系统内，同一用户的一次身份认证**可以**供该用户的多项业务授权使用，不要求每项业务必然重验，也没有要求必须复用。比如，甲已完成身份认证、已获准使用 MCPTT，随后打开 MCVideo。不能因没有第二次身份认证就判 MCVideo 失败，也不能因为 MCPTT 已通过就放行 MCVideo。要确认 MCVideo 的结果，查甲这次对应的 MCVideo 业务授权；没有结果就记为未确定，不写成拒绝。这项复用说的是同一用户的认证，不是转让给另一用户的权限。[§10.6.1 步骤 1、末注，印 115](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=116)。

若问题是“一份共享 REGISTER 是否也在申请 MCPTT 授权，要核哪些消息材料”，查[共享 SIP 注册与 MCPTT 业务授权](shared-sip-registration.md)；“在注册阶段认证用户”本身并不回答这道报文题。若用户要把业务迁到伙伴系统，查[伙伴系统的迁移授权](partner-migration-authorization.md)，不能拿主系统单域示例替代迁移流程。

# 功能别名应提供给谁？迟入终端、接收方和归属名单分别看什么？

功能别名可以在迟入时提供，也可以随发送参与者信息提供，或者列入按请求返回的归属名单。这三项看的是不同条件。依据为 3GPP TS 22.280 V16.8.0（Release 16，Stage 1）[§5.9a.2，印刷页 24](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=25)。

| 在判断什么 | MCX 业务须提供什么 |
| --- | --- |
| **终端迟入组通信（R-5.9a-026）** | 按 §5.3 向迟入的 MCX UE 提供正在发送的组成员的功能别名，保留 §5.3 的别名可得条件。若甲正在发送、乙的终端后来加入，给乙的是甲的别名。-026 把迟入字样放在发送成员之后，句法不清；它明引的 §5.3 R-5.3-002 写明迟入者是接收信息的终端，不要求发送者本人迟入。[§5.3，印刷页 15](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=16) |
| **向接收方标识正在发送的参与者（R-5.9a-028）** | 须向接收侧 MCX 用户（UE）提供与发送参与者的 MCX 业务用户 ID 关联的功能别名，除非该参与者的身份按 §6.4.3 受限。这里提供的是与该 ID 关联的别名；不能把它当成 ID 本身。[§6.4.3，印刷页 31](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=32) |
| **按请求返回当前归属名单（R-5.9a-029）** | 对名单中的每名已归属成员，须给出其 MCX 业务用户 ID 和关联的功能别名。名单不是全体成员，也不是当前呼叫参与者。请求和授权按 §6.4.5 查；获授权的用户不因本人未归属而失去查询资格，用户与 UE 的授权也不能互相代替。[§6.4.5，印刷页 31–32](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=32) |

-029 明写的是用户 ID **和**关联的功能别名，不能用 §6.4.5 对一般标识的“和／或”将两类内容改成任选。没有关联功能别名时，这项没有要求为成员造一个别名。该条是按请求提供名单，不规定自动收名单变化时的字段。[R-5.9a-029，印刷页 24](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=25)；[§6.4.5 R-6.4.5-004，印刷页 32](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=33)。

第 5 章供在网、离网共用，[表 A.1（MCPTT），印刷页 64](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=65)、[表 B.1（MCVideo），印刷页 75](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=76)、[表 C.1（MCData），印刷页 86](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=87) 的 §5.9A 行均列这三项。被引用的条款仍须看自身的适用范围。例如，C.1 在 §5.9A 列出 -026，但其 §5.3 行标 NA，不能从这条功能别名要求推出 MCData 也须实现 §5.3 的整套迟入机制。[第 5 章标题，印刷页 12](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=13)；[表 C.1 的 §5.3 行，印刷页 84](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=85)。§6.4.3 和 §6.4.5 是第 6 章的在网要求，不能借此断定离网流程。[第 6 章标题，印刷页 29](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=30)

# 谁能创建用户别名？用户 ID 可关联什么别名，终端要能显示什么？

当一台终端上没有显示某个别名时，要分清三个问题：谁有权创建它，它关联哪个标识，终端是否具备可配置的显示能力。这三项要求的责任方不同。

**谁能增删？** MCX 业务须让获授权方能够为 MCX 用户及其关联的业务用户配置档创建和删除别名。这里说的是“获授权方”，不是只指业务管理员。删除的是别名，不是用户或配置档。[R-5.7-001，印刷页 21](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=22)。

**谁给用户 ID 分配别名？** 业务须提供关联机制，使每个 MCX 业务用户 ID 都能关联一个由 MCX 业务管理员分配的字母数字标识。这个标识就是别名，长度下限记作 `Nc3`。这项要求说的是每个 ID 都能关联，不说明某个 ID 已配了别名，也不把增删所有别名的权限限定给管理员。[R-5.7-002，印刷页 21](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=22)。信息性[表 E.1 的 Nc3 行，印刷页 96](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=97)解释了这个变量，没有给出字符数。

**终端要能显示什么？** 所有 UE 都须提供可配置的显示能力，能显示 MCX 业务用户 ID，以及分别与以下三者关联的别名：该用户 ID、所选 MCX 业务组、任务关键组织名称。所选组是某位已归属成员用于发送的组。条款没有要求这些信息一直在屏幕上，也没有规定显示设置由谁操作。单看某次截图，无法断定终端是否提供这项能力。[R-5.7-003，印刷页 21](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=22)；[§3.1 所选组定义，印刷页 11](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=12)。

若要查**在网业务向接收终端提供什么**或**怎样保证 ID 和别名唯一**，见[在网 ID 和别名管理](onnetwork-id-and-alias-management.md)；在网组通信对发送者身份的要求见[组通信中的用户、组与别名](onnetwork-group-sender-identification.md)。若要区分业务用户 ID 和认证、路由用的身份，见[跨业务身份映射](cross-service-user-mapping.md)。这些问题不改变终端自身的显示要求。

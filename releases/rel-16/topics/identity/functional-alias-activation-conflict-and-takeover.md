# 功能别名已被占用，何时提示占用、并发启用或提供接管？

**先看这个别名的占用策略。** 系统支持功能别名时，MCX 业务须让业务管理员创建、删除和管理别名。管理员能逐别名指定三种情况之一：允许**多人同时启用**，人数上限可按别名配置；允许**获授权用户接管**；两种都不允许。这不是一个适用于所有别名的统一设置。[R-5.9a-005，印刷页 22](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=23)。

| 申请启用或接管时的条件 | 业务须做什么 |
| --- | --- |
| 已有另一名用户启用，且有下列一种情况：别名不允许多人同时启用，或并发人数已达上限 | 告知申请者别名已在用。提示占用本身不是拒绝或接管结果。[R-5.9a-006，印刷页 22](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=23)。 |
| 已有至少一名其他用户启用，允许多人同时启用，且人数未达上限 | 为申请者启用，并通知其他**所有**同别名用户。见 [R-5.9a-007，印刷页 22 的起句](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=23)及[印刷页 23 的续句](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=24)。 |
| 获授权用户申请启用正被别人使用的别名，允许接管，且没有标为允许多人同时启用 | 给申请者提供接管选项。提供选项不等于原使用者已停用。[R-5.9a-008，印刷页 23](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=24)。 |
| 获授权用户已接管原先为另一人启用的别名 | 为接管者启用，并告知原用户该别名已停用。条文不规定启停与通知的顺序。[R-5.9a-009，印刷页 23](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=24)。 |

**人数已满时，正文与业务适用表要分开读。** [R-5.9a-008a，印刷页 23](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=24) 写的是：获授权用户尝试启用时，已有至少一名其他用户启用，且同时启用人数已达上限，业务须拒绝请求。表 A.1、B.1、C.1 的完整 5.9A 功能别名行组均未列 -008a。这不是表里明写 NA，也不是正文缺失。不能拿 -006 的占用告知代替 -008a 的拒绝，或用 -006 的表列结果断定 MCPTT、MCVideo、MCData 必须按 -008a 拒绝。未列也不表示可以超过上限。

这是 3GPP TS 22.280 V16.8.0（Release 16，Stage 1）[第 5 章的在网和离网共用要求，印刷页 12](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=13)。规范性[表 A.1（MCPTT），印刷页 64](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=65)、[表 B.1（MCVideo），印刷页 75](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=76)、[表 C.1（MCData），印刷页 86](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=87)。三表均列 -005、-006、-007、-008、-009，但未列 -008a。

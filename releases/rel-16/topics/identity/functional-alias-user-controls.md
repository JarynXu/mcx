# 功能别名怎样启停？候选名单、某人的活动别名和启用结果有何不同？

“东区值班”这个功能别名代表一项任务。在支持功能别名的系统里，甲先用自己的 MCX 用户 ID 登录业务，再启用获准使用的别名；他可以同时启用不止一个。登录回答“甲是谁”，启用回答“甲现在以哪个岗位身份工作”；完成业务登录或 SIP 注册，都不足以证明甲已经启用某个别名。见[§5.9a.1 概述，印刷页 22](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=23)。

## 谁能启停，谁来授权？

系统支持功能别名时，MCX 业务须给用户提供**启用一个或多个别名**的机制。这些别名供该系统内的 MCX 用户使用；该系统是别名的主 MCX 业务系统。业务也须给用户提供**停用功能别名**的机制。停用“东区值班”不等于删除这个别名或退出业务。见[R-5.9a-001，印刷页 22](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=23)、[R-5.9a-003，印刷页 22](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=23)。

在同一支持条件下，业务须让 MCX 业务管理员能授权用户**启用、停用、查询和接管**功能别名。能授予接管权限，不代表用户已获准接管或已经接管；这条也没有规定四种权限应怎样组合。见[R-5.9a-012，印刷页 23](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=24)。

## 三个问题，三种答案

| 问题 | 业务要求 |
| --- | --- |
| 甲可以从哪些别名中选一个来启用或停用？ | 系统支持功能别名时，用户请求后，业务须给他一份可供选择的名单。附注说名单可以考虑位置、值班安排等情境，并未要求必须这样筛选。这不是甲当前启用了哪些别名的清单。见[R-5.9a-004，印刷页 22](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=23)及其附注。 |
| 乙想知道甲当前启用了哪些别名？ | 系统支持功能别名且乙获得授权时，乙须能向系统按**指定用户甲**查询其活动别名。用“东区值班”反查所有启用者是相反方向，不是这条要求。见[R-5.9a-011，印刷页 23](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=24)。 |
| 甲申请启用后，现在是什么状态？ | 系统须具备告知用户启用状态的机制。“已接受”“待处理”“已拒绝”是例子，不是必经的三个步骤。仅看到申请或“待处理”，不能说别名已启用。见[R-5.9a-025，印刷页 24](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=25)。 |

**名单里没有“东区值班”，还能启用吗？** 如果系统支持功能别名，且已在系统中定义了它，业务须允许用户启用这个未列出的别名。不能只因未列出就判定无法启用，也不能把任意输入的新名称当成已定义别名。这一条不取消授权要求。见[R-5.9a-010，印刷页 23](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=24)。

要判断启用后[组内怎样用别名以及从哪里可以找到用户](functional-alias-group-use-and-reachability.md)，查另一个 Stage 1 问题。只有需要在网过程时，才查 Stage 2 的[按用户或按别名查询](active-functional-alias-lookup.md)；判读在网 MCPTT 的协议申请和通知，查 Stage 3 的[客户端启停与状态判读](mcptt-functional-alias-client.md)。本页没有指定注册消息、接口或响应码。

# SIP-3 连哪两端？跨信任域要改什么？

**SIP-3 的两端是两个 SIP 核心。** 这条参考点用于建立支持 MC 业务的会话，须使用 TS 23.002 定义的 **Mm 和 ICi**。名称指两端的功能角色，不指某个 MC 网关、物理跳点或某笔请求的路由。[TS 23.280 V16.7.0，Release 16，Stage 2，§7.5.3.4，印刷页 42](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=43)

本节列出三项用途：**事件订阅与通知、会话管理、媒体协商**。只看到 SIP-3，不能判断订阅的是哪个对象，或媒体已传到对端。若要查某条订阅或通知是否属于组配置互连或用户配置迁移，按[配置订阅与通知的业务端点](../groups/partner-group-configuration.md)核对，不能用 SIP-3 的名称替代 CSC-19、CSC-20 或 CSC-21 的适用条件。

本版编者注把**不同信任域的服务器之间使用 SIP-3 是否需要修改**标为 FFS（待进一步研究）。这不是跨域禁令，也没有给出必须修改或可以原样部署的结论。本节不说明某次交换须走 Mm 或 ICi 中的哪条实际路径。

查[终端迁移注册所用的 SIP-1 和 Cx](migration-registration-reference-points.md)或[SIP 核心与 SIP AS 之间的 SIP-2 和注册通知](sip2-reference-point.md)时，先认清两端。不要从双核心链路推定终端已注册或业务已授权。

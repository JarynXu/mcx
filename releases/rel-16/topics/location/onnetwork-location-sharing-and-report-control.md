# 谁能限制自己位置的传播？一次与周期位置报告分别能为谁启停？

甲的 MCX 终端向乙、丙的 MCX 终端传输时，业务须在**隐私限制允许的范围内**向接收终端提供甲终端的位置。这里的接收方是乙、丙，不是所有已注册或已归属的用户。见[R-6.12-001，印刷页 44](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=45)。若甲获授权，业务还须让**甲限制自己位置的传播**；这项权限不等于替乙决定是否共享乙的位置。条款没有指定谁授予权限，也没有要求每次传输都弹窗询问。见[R-6.12-003，印刷页 44](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=45)。

**位置一定是从 3GPP 位置服务取的吗？** [R-6.12-002，印刷页 44](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=45) 要求 MCX 业务能传送由 3GPP 位置服务提供的信息。它约束的是传送能力，既没有要求每次报告都去取数，也没有把 3GPP 位置服务定为唯一来源。

## 一次与周期报告：目标不完全相同

下列三种操作，MCX 业务都须为**获授权的 MCX 用户**提供手段。“谁操作”与“报谁的位置”是两个问题。

| 操作 | 条文列出的报告对象 |
| --- | --- |
| 启动一次性位置报告 | 某一 MCX 用户。见[R-6.12-006，印刷页 44](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=45)。 |
| 启动周期性位置更新报告 | 某一 MCX 用户，或某个**特定功能别名**。见[R-6.12-006，印刷页 44](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=45)。 |
| 停用周期性位置更新报告 | 某一 MCX 用户。见[R-6.12-007，印刷页 44](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=45)。 |

例如，调度员获准启动“北站值班”的周期报告，依据是 -006 的周期分支。要改为按这个别名只查一次，不能沿用同一句得出 Stage 1 也要求这样做。要按别名停报，-007 也没有列出这个目标。**未列出不等于禁止。** 若要查按已激活的共享功能别名一次或周期获取位置的具体程序，见[Stage 2：按共享功能别名查位置](active-alias-trigger.md)。能启动报告也不等于报告已到达；停用某用户的周期报告不等于关闭这个用户的一切位置业务。

## 位置信息保密，与认证消息，是两件事

- **谁能读到位置？** 业务须为位置信息提供端到端机密性。只看到中间某一跳加密，不能据此确认端到端都受到保护。[R-6.12-004，印刷页 44](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=45) 没有指定网络端点角色或加密算法。
- **认证什么？** 业务须认证承载位置信息的**消息**。即使一条昨天生成的消息通过了认证，也不能据此把其中的坐标当作用户今天的实际位置；消息认证不核定坐标的准确性或新鲜度。见[R-6.12-005，印刷页 44](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=45)。

这些业务要求没有指定 API、SIP 方法、LMS 注册或配置下发时机。若要查某次按需查询中如何检查许可、位置可从哪来，读[按需查询的许可与位置来源](on-demand-location-consent-and-source.md)；若问何时向 LMS 上报或怎样取消终端上报，读[终端位置上报配置](event-reporting-configuration.md)；若要对某份用户清单订阅或退订，读[向 LMS 订阅用户位置](user-subscription.md)。这些 Stage 2 主题各有前提，不是 §6.12 规定的后续步骤。

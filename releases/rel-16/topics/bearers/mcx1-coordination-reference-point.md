# MCX-1 是不是只用于跨系统？同一对网关之间的配置通知也走 MCX-1 吗？

**不能按网关地址或系统数量选参考点。** Rel-16 公共架构把 MCX-1 用于 MC 业务服务器间的协调，例如优先级协调；它不是公共服务核心（common service core）的功能。两端即使在同一个 MC 系统中、或者两个业务服务器分别服务不同种类的 MC 业务，这两点也不排除 MCX-1。这里依据 TS 23.280 V16.7.0 的 Stage 2 定义，判断功能角色和交互用途，不据此填写线上报文或端口。[§7.5.2.19，印 41](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=42)

## 什么样的两端可以构成 MCX-1？

§7.5.2.19 列了三种功能组合：**MC 业务服务器与 MC 业务服务器、MC 业务服务器与 MC 网关服务器、MC 网关服务器与 MC 网关服务器**。这些功能可在同一个或不同 MC 系统；业务服务器可同类或异类。先查这笔实际操作是不是业务服务器协调，再看这两个功能角色是否匹配。服务器名称、地址相同、两边用的是同种业务，或链路跨系统，都不能单独选出 MCX-1。[§7.5.2.19，印 41](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=42)

**定义可以跨系统，不代表每种协调程序都可以跨信任域。** 例如 §10.12.3 的多服务器优先级仲裁假定所有参与的 MC 业务服务器处于同一信任域；本版对能否向异域服务器执行已授予的优先级仍标为待研究（FFS）。只有接口名称，不能证明这套仲裁已经启用、某次请求已获准，或它的跨域执行已经定义。[§10.12.3 首段、前提 2 和编者注，印 190](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=191)

## 网关也发送配置订阅通知，怎么换一张表查？

即使两笔记录涉及同一对网关，也要看这次查的是不是**跨系统共享配置的订阅通知**，而不是服务器优先级协调。先沿这条配置的功能路径看：

| 两端功能和用途 | 查哪个参考点 |
| --- | --- |
| 组管理服务器（GMS）和 MC 网关：为跨系统组呼共享组配置的订阅／通知 | **CSC-19**；用 SIP-2、SIP-3 传送和路由相关信令。 |
| 配置管理服务器（CMS）和 MC 网关：为迁移共享用户配置的订阅／通知 | **CSC-20**；也用 SIP-2、SIP-3。 |
| 不同 MC 系统、不同安全域的两个 MC 网关：为互联或迁移共享组配置、用户配置的订阅／通知 | **CSC-21**；用 SIP-3。 |

例如，已核实 A、B 是两个不同安全域系统的 MC 网关，记录的是跨系统组配置通知，这段应按 CSC-21 查。若抓到的是 A 的 GMS 与 A 网关之间、属于同一组配置订阅的那一段，则按 CSC-19 查，不能把整个流程的每一跳都记成 CSC-21。只见 SIP-3 或一对 MC 网关，不能断定其传的是哪一类业务信息，也不能把三条 CSC 参考点套到所有网关操作上。[§§7.5.2.20–.22，各端点、用途和承载，印 41](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=42)

**也不能把 MCX-1 填成 MCPTT-3、MCVideo-3 或 MCData-3 的别名。** §7.5.2.19 的编者注把它与这三条业务参考点的关系留为 FFS。强行合并或规定必定互斥，都超出这段定义。[§7.5.2.19 编者注，印 41](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=42)

若已经确定采用[多业务服务器优先级仲裁](multi-server-priority-arbitration.md)，查实际的申请、授予和发给旁边服务器的通知。若这次是在[伙伴系统间共享组配置](../groups/partner-group-configuration.md)，查它的取档、订阅和通知流程，而不是从参考点名称推定配置已应用。

# 离网直连要用哪种终端，业务须能事先为它配好什么？

**有网也能用离网直连。** 这里的“离网”看业务通信走哪条路：用户在覆盖外，或在覆盖内选用 ProSe 终端直连，业务传输都不经过网络基础设施。用户要在直连通信范围内。在覆盖内选用直连时，与网络或业务的信令仍可能可用。见 [§7.1 概述，印刷页 50](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=51)及[注 2，印刷页 51](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=52)。

用直连路径开展离网 MCX 业务，终端必须是支持公共安全 ProSe 的 UE（Public Safety ProSe-enabled UE）；离网业务须使用 TS 22.278 所定义的这类终端之间的 ProSe 直连通信能力。这分别是**对终端和对业务**的要求。见 [R-7.2-001、-002，印刷页 52](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=53)。

若终端可能得不到网络服务，MCX 业务须提供预配置机制，供业务管理员、获授权用户或两者使用。为离网使用准备的内容有两部分：

* **按预期使用者关联的业务用户配置档**：列出供该用户使用的离网业务组、已获授权离网业务组的字母数字别名标识、每位预期使用者的业务用户 ID，以及每个用户 ID 对应的字母数字别名。最小长度 Nc3 限定的是最后一项，不能凭此条给组别名也设定 Nc3。
* **密钥**：认证密钥和端到端安全密钥。

这项要求针对业务提供的预配置能力，不要求两类人员共同操作，也不要求终端必须先掉网。条文的注说明，既可在网络覆盖外配置，也可接入网络配置。见 [R-7.2-003 及其注，印刷页 52](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=53)。要区分离线配置中各服务器和终端的职责，见[离网配置角色（Stage 2）](../groups/offnetwork-configuration-roles.md)；要查组号与组播 IP 的关系，见[离网组的 ProSe 寻址（Stage 2）](../groups/offnetwork-prose-addressing.md)。

依据：3GPP TS 22.280 V16.8.0，Release 16，Stage 1。规范性表 [A.1（MCPTT，印刷页 70）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=71)、[B.1（MCVideo，印刷页 81）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=82)、[C.1（MCData，印刷页 92）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=93) 均列出这三项。

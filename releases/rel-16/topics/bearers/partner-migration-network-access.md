# 迁到伙伴 MC 系统，手机还连着原来的移动网或 SIP 核心，算故障吗？

不一定。迁移改变的是给用户提供 MC 业务的系统。手机通过哪个移动网接入、用哪个 SIP 核心（IMS）访问伙伴，是两个分别配置的选择。Rel-16 推荐使用伙伴的归属移动网（HPLMN）和伙伴的 SIP 核心，但“没换”本身不足以判故障。[3GPP TS 23.280 V16.7.0，Stage 2，§5.2.9.2，印 22](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=23)；[§5.2.9.2 续及 §5.2.9.3，印 23](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=24)

## 查移动网：用户实际上是从哪个网访问伙伴的？

设主系统为 A，伙伴系统为 B。用户宜通过 B 的 HPLMN 访问 B 的业务，也可以通过 A 的 HPLMN。两家 MC 业务提供方的协议决定用哪一种；对已开通迁移的用户，**必须提供配置，指明迁往各个 MC 系统分别可用哪些 PLMN**。即使 A、B 的归属网不同，若双方约定经 A 网访问 B，用户的配置也允许这么做，那就不因手机仍在 A 网而判错。反过来，用户的 EPS 签约还归 A，也不证明手机此刻在 A 网：它可能已漫游到了 B 网。[§5.2.9.2 首段及注 2，印 22](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=23)；[配置要求及两个接入分支，印 23](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=24)

**若 A、B 的 HPLMN 不同，用户漫游到 B 的 HPLMN，要核三项：**

| 查哪里 | 核什么 |
|---|---|
| A、B 两网之间 | 需要 EPC 层漫游。 |
| B 的 HPLMN | 这个网需要为标识 B 的分组数据网（PDN）的 APN 启用本地分流（local break-out）。这里查的是 B 的网络设置。 |
| A 网的 EPS 签约 | **获准迁往 B 的用户所用的签约**需要配置这些 APN，并为它们启用本地分流。 |

这里的 APN 是 §5.2.7 所指、标识伙伴系统 PDN 的接入点名称。例如，前两项有记录，A 的签约也列出了伙伴 APN，只缺其分流状态，应填“主侧待核”。查明 A 的签约关闭了这些 APN 的分流，才可填“不符合”。若三项及所需的 APN 接入凭据都已核实，不需要再向 B 索取来访用户在 B 的另一份 EPS 签约来证明这三项。[§5.2.9.2，异网漫游分支的三项及注 3，印 23](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=24)

**若 A、B 共用同一个 HPLMN，用户继续通过这个网接入：**A 网中获准迁往 B 的用户所用的 EPS 签约**仍需配置标识 B 的 PDN 的 APN**。共网分支没有要求两网之间的 EPC 漫游，也没有规定必须开或关本地分流。不能因没有跨网漫游回执而退单，也不能因共网而漏配伙伴 APN。两种分支都一样：若访问这些 PDN 需要凭据，APN 配置还应包括所需凭据；不需要凭据时无须另造一套。[§5.2.9.2，共网分支及注 3，印 23](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=24)

## 查 SIP 核心：终端针对这个伙伴选的是哪个？

推荐使用伙伴的 SIP 核心，但**连通条件和安全策略都允许**时，可由同一个 SIP 核心连接主系统和一个或多个伙伴系统。采用共用安排由两家提供方约定。对可迁移用户的终端，**每个伙伴都必须有选择配置**：访问该伙伴时，是用主核心，还是另接伙伴核心。已漫游到 B 网，不等于必须改接 B 的 SIP 核心。[§5.2.9.3，推荐、共用条件、注 2 及首项配置，印 23](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=24)

例如，对伙伴 B，双方同意共用，连通和安全策略允许，终端也配置为连主核心。此时沿用主核心就符合该选择；本条不要求再为 B 备一套只在另接核心时才需的注册凭据。对伙伴 C，若终端配置为另接 C 的核心，就**还必须给终端配置接入 C 核心所需的资料，以及向 C 核心注册所需的凭据**。已有 PDN 接入凭据不能代替后者。若确认缺少所需的 SIP 注册凭据，C 的配置不全；如果两项都齐，能签的是接入准备，不能据此认定已经注册成功。本版将终端如何连接伙伴 SIP 核心的具体办法留待研究。[§5.2.9.2 注 3 及 §5.2.9.3 末两项、编者注，印 23](https://www.etsi.org/deliver/etsi_ts/123200_123299/123280/16.07.00_60/ts_123280v160700p.pdf#page=24)

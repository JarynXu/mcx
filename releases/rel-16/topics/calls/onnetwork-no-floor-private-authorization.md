# 在网无话权控制私通信：管理员能配哪些发起权限和通信对象？

**谁可发起哪种私通信**和**某位获授权用户能与谁通信**是两类配置。第二类还要分清方向：他可向谁发起，和他可接收谁发来的私通信。这里讨论 3GPP TS 22.280 V16.8.0（Release 16）的在网无话权控制私通信（Private Communication）Stage 1 要求。[第 6 章，印刷页 29](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=30)；[§6.7.3，印刷页 38（PDF 第 39 页）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=39)。

**不区分开始方式时，业务宜提供发起授权的配置机制。** [R-6.7.2-002，印刷页 37](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=38) 用 *should*：MCX 业务宜让业务管理员配置其权限范围内哪些 MCX 用户获准发起无话权控制的私通信。能配置谁可发起，不代表某个用户已经获准，更不能证明某次通信已建立。

下列四项规定业务**须**提供哪些配置机制：

| 要配置的权限 | MCX 业务须向业务管理员提供的能力 |
| --- | --- |
| **手动开始**的发起权限 | 配置其管理权限范围内哪些 MCX 用户可发起手动开始（Manual Commencement）的无话权控制私通信。[R-6.7.3-005，印刷页 38](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=39)。 |
| **自动开始**的发起权限 | 配置其管理权限范围内哪些 MCX 用户可发起自动开始（Automatic Commencement）的无话权控制私通信。[R-6.7.3-006，印刷页 38](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=39)。 |
| 某位获授权用户的**发出**范围 | 给该用户配置同一管理权限内的 MCX 用户集合，他可以向集合中的人发起无话权控制私通信。[R-6.7.3-007，印刷页 38](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=39)。 |
| 某位获授权用户的**接收**范围 | 给该用户配置同一管理权限内的 MCX 用户集合，允许集合中的人向他发起无话权控制私通信。[R-6.7.3-007a，印刷页 38](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=39)。 |

手动开始和自动开始是通信的开始方式。前两条规定管理员能配置谁有权发起以该方式开始的私通信，不规定被叫怎样接听或怎样设置。业务须分别支持这两种权限配置；一项已配置不证明另一项的值。四条均为必须提供的管理机制，不以正有一场私通信或成员同属一个组为能力前提。

例如，甲与乙都在同一管理权限内，乙列在获授权用户甲的**发出**集合。它描述的是甲到乙方向，不说明乙能否向甲发起，也不说明甲的**接收**集合或乙的接收配置。只凭一份名单，不能判断甲这次是否能建起私通信。本节没有规定名单是否对称、配置默认值、权限覆盖关系、集合如何合并或如何处理一次实际请求。

**适用业务：** 表 A.1（MCPTT）、B.1（MCVideo）、C.1（MCData）均在 §6.7.2 列 -002，并在 §6.7.3 列上述四项。[表 A.1，印刷页 67](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=68)；[表 B.1，印刷页 78](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=79)；[表 C.1，印刷页 89](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=90)。

# 在网无话权控制私通信期间，终端还能同时接收哪些传输？

一台 MCX 终端正在一场**无话权控制的私通信**中接收和发送。在**同一项 MCX 业务**内，业务还须允许它同时接收下列传输：

| 传输来自哪里 | 条件 |
| --- | --- |
| 其他组通信 | R-6.14-001 没有对这些组通信是否有话权控制作限定。 |
| 其他私通信 | R-6.14-002 限于**有话权控制**的其他私通信；无话权控制的是终端正在收发的那一场。 |

[TS 22.280 V16.8.0 §6.14，印刷页 45](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=46) 分别要求业务支持这两种情形，不是任选其一，也没有要求两类其他通信必须在同一时刻一起接收。对其他通信，两项写的都是**接收传输**，没有要求终端也向它们发送。收到传输不等于用户已经听到或看到内容；本节没有指定混音、显示顺序、媒体路由或会话数量上限。

这是 Release 16 的 Stage 1 要求，限于[第 6 章的在网情形（印刷页 29）](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=30)。规范性表 [A.1（MCPTT），印刷页 68](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=69) 和 [B.1（MCVideo），印刷页 79](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=80) 都列出正文的两个编号。[C.1（MCData），印刷页 90](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=91) 在同一行列出 `R-6.14-001` 和 `R-6.14.002`。后一项按同节第二项与正文 `R-6.14-002` 对应，表中最后一个分隔符是点号，不是连字符。

若问私通信与其他通信是否分别比较传输和呈现的优先级，查[在网私通信的传输与呈现优先级](onnetwork-private-communication-priority.md)。若是一边用 MCPTT、一边用 MCVideo，查[不同 MC 业务并行时的终端资源](../media/concurrent-services-ue-resources.md)。

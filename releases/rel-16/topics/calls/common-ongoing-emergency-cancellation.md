# 谁能取消组的进行中紧急状态，取消后通知谁？

**组的进行中紧急状态可以由获授权的用户取消；取消后，业务须通知已归属该组的成员，并告知取消用户的身份。** 组状态、用户的业务紧急状态和单独的紧急告警不是同一件事。这里依据 3GPP TS 22.280 V16.8.0（Release 16，Stage 1）的在网与离网共用要求。[第 5 章标题，印刷页 12](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=13)、[§5.6.2.2.2，印刷页 19](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=20)

| 取消依据 | MCX 业务须支持什么 |
| --- | --- |
| 获授权用户（R-5.6.2.2.2-001） | 由获授权的 MCX 用户取消该业务组的进行中紧急状态。已经归属该组不等于拥有取消权。 |
| 管理员设定准则（R-5.6.2.2.2-002） | 管理员设定的取消准则满足时，业务须支持取消该组的进行中紧急状态。超时是例子。条款没有规定统一的超时时长、计时起点或到期自动取消。 |
| 紧急组通信的发起者（R-5.6.2.2.2-003） | 发起者能取消该组的进行中紧急状态和一名 MCX 用户的业务紧急状态。条款没有细化这名用户是否只能是发起者本人，也没有授予任意代取消权，或要求同一个操作同时清除两种状态。 |

**谁能授权？** 业务须提供机制，让 MCX 业务管理员授权一名 MCX 用户取消进行中紧急状态。设定取消准则和授权用户是两件事。管理员能授权，不等于这名用户已经获准，也不要求管理员本人执行取消。[R-5.6.2.2.2-005，印刷页 19](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=20)

**通知看是否已归属，不看是否参加了这场通信。** 丙已归属该组但没有参加，仍在取消通知的范围内。通知须包括组状态已取消和执行取消的 MCX 用户身份。条款没规定标识用什么字段、成员是否回执，也没有交代管理员准则满足而无取消用户时怎样表示身份。不能仅因某人设定过准则或发起过通信，就把他写作取消者；也不能因此省略取消通知。[R-5.6.2.2.2-004，印刷页 19](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=20)

在这五项要求中，MCPTT、MCVideo 和 MCData 的适用性相同。[表 A.1，印刷页 63](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=64)、[表 B.1，印刷页 74](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=75)、[表 C.1，印刷页 85](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=86) 的 §5.6.2.2.2 行逐项列出五个编号。上一级标题行标注的 NA 不覆盖这些编号。

取消组状态不证明用户状态已解除、另有告警已撤销或呼叫已释放。若问独立告警谁可代撤，见[在网代撤独立紧急告警](onnetwork-emergency-alert-cancellation-authorization.md)。若问离网紧急组通信自身取消后的通知，另查[第 7 章的离网紧急组通信](offnetwork-emergency-group-communication.md)，先确认该条所列业务，不能沿用本页的适用范围。要查具体取消过程，按场景读[MCPTT 控制功能的已有组状态取消](emergency-group-server.md)、[在网 MCVideo 组紧急状态取消](../mcvideo/group-emergency-state-cancel.md)或[在网 MCData 组 SDS 紧急状态取消](../mcdata/group-sds-emergency-cancel.md)。

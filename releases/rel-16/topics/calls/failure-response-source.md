# MCPTT 拒绝请求时，Response-Source 能指出哪种功能？

一次普通 MCPTT 私呼的 INVITE 返回 403，Warning 头的警告码是 399，文本编号是 145。要排查是哪一段拒绝，先把 SIP 状态、业务原因与生成这份响应时的服务器角色分开。

## Response-Source 指出的是生成这份响应时的角色

MCPTT 服务器对收到的请求**发起失败响应**时，可以按运营策略加入 SIP `Response-Source`。固定版给出 `fe` 参数使用的 URN 命名空间 `urn:3gpp:fe`、其中的 fe-id `as`，以及随服务器当前角色填写的 `role`：

| `role` 值 | 该服务器生成响应时所承担的角色 |
| --- | --- |
| `pf-mcptt-server` | 参与功能（PF） |
| `cf-mcptt-server` | 控制功能（CF） |
| `ncf-mcptt-server` | 非控制功能（NCF） |

抓到符合这条构造的字段，可以把值用作这份响应的角色证据；`pf-mcptt-server` 本身不分主叫侧与被叫侧。同一 MCPTT 服务器可以承担不止一种功能，所以角色值也不是物理服务器或实例 ID。只看最后一次转发的节点，不能替代生成该响应的角色。这里不定义整条头的解析、验证或跨段保留规则。

**没有 Response-Source，不能据此排除任何 MCPTT 服务器角色，也不能说拒绝一定出自代理。** 是否加头受运营策略影响；在某一处没抓到，不足以解释它为何缺失。想继续追，找同一请求各段的接收记录和生成失败响应的记录，区分本段回复与从后段转送的响应。

依据：[TS 24.379 V16.14.0（Rel-16，Stage 3）§§5.3.1–.2，印刷页 51–52](https://www.etsi.org/deliver/etsi_ts/124300_124399/124379/16.14.00_60/ts_124379v161400p.pdf#page=52)；[§5.3.3，印刷页 54](https://www.etsi.org/deliver/etsi_ts/124300_124399/124379/16.14.00_60/ts_124379v161400p.pdf#page=55)。

## 私呼同样回 403、文本 145，还不足以选定 O-PF 或 CF

MCPTT 服务器在对 INVITE 的响应中附加这类文本时，§4.4 规定 `Warning` 的警告码为 399，主机名用该 MCPTT 服务器的主机名。引号内开头的三位数才是 MCPTT 文本编号。例中的 **403 是 SIP 状态码**，**399 是 Warning 警告码**，**145 是业务文本号**；后两项也不是角色枚举。主机名和本段当前角色是两份信息。

在这里比较的普通按需私呼中，若收到的 INVITE 缺少 `application/resource-lists` 正文，主叫侧参与功能（O-PF）和控制功能（CF）的**各自接收程序**都规定返回 403、文本 145 并停止。在两者的普通私呼列表条件下，正文含多个 `entry` 也有同一失败结果。这两项按各自收到的请求检查，不是一份 INVITE 必须依次经过的两次拒绝。两段都没规定零条目一定适用同样的分支。

有两处文字不能代替实际执行角色：表 4.4.2-2 在 145 的说明中提到参与功能，但 CF 程序也明确用 145；CF 程序第 4 项把被拒请求称作发给 O-PF 的 INVITE，该项仍位于 CF 收到请求后的程序。不要只依表中说明或请求名称把 CF 排除。查上述准入细节、其他拒绝原因及各段转送条件，见[普通按需私呼的服务器准入](private-server-admission-routing.md)。

依据：[§§4.4.1–.2 及表 4.4.2-1，印刷页 33–34](https://www.etsi.org/deliver/etsi_ts/124300_124399/124379/16.14.00_60/ts_124379v161400p.pdf#page=34)，[表 4.4.2-2 的 145 项，印刷页 37](https://www.etsi.org/deliver/etsi_ts/124300_124399/124379/16.14.00_60/ts_124379v161400p.pdf#page=38)，[§11.1.1.3.1.1 第 8–9 项，印刷页 366–367](https://www.etsi.org/deliver/etsi_ts/124300_124399/124379/16.14.00_60/ts_124379v161400p.pdf#page=367)；[§11.1.1.4.2 第 3–4 项，印刷页 379–380](https://www.etsi.org/deliver/etsi_ts/124300_124399/124379/16.14.00_60/ts_124379v161400p.pdf#page=380)。

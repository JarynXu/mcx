# 在网私通信中，怎样按用户的当前位置联系本地调度员？

看**发起通信的 MCX 用户自己的当前位置**。在网 MCX 业务须提供一种机制，让用户按这个位置与本地调度员进行私通信。例如，用户平时在甲区，今天到乙区执勤；若当前位置由乙区调度员负责，业务须让他能按这个位置联系乙区调度员。只看到他能拨通甲区的固定号码，不能证明业务满足这项要求。见 [TS 22.280 V16.8.0（Release 16，Stage 1）R-6.7.2-004，印刷页 37](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=38)。

**“本地”不等于直线距离最近。** 条文没有指定怎样取得位置、怎样选人或用何种地址路由，也没有要求用户一跨区就把正在进行的私通信转接给另一个调度员。私通信可有话权控制，也可没有；本项没有限定其中一种。见 [§6.7.1、§6.7.2，印刷页 37](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=38)。[表 A.1（MCPTT），印刷页 67](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=68)、[表 B.1（MCVideo），印刷页 78](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=79)、[表 C.1（MCData），印刷页 89](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=90) 均列出 -004，分别适用于 MCPTT、MCVideo、MCData。

用户按位置能联系谁，与管理员如何定义可关联调度员的地理区域是两个问题。区域管理见 [R-6.1-005，印刷页 29](https://www.etsi.org/deliver/etsi_ts/122200_122299/122280/16.08.00_60/ts_122280v160800p.pdf#page=30)。若问业务是否必须每次从 3GPP 位置服务取数，读[在网位置传送与报告要求](../location/onnetwork-location-sharing-and-report-control.md)；若问管理员能配置哪些用户发起无话权控制私通信，读[发起授权与收发对象](onnetwork-no-floor-private-authorization.md)。只有配置或位置报告，不足以证明调度员已收到这次私通信。

# 从 MCVideo 服务器回放一段录像：有了 URL，能播放、快进和快退吗？

录像 URL 指向文件，不代表持有它的人有权播放。这里讲的是在网 MCVideo：客户端请求回放服务器上已经存好的录像，视频从服务器流向客户端。

**开始播放前，服务器还要查什么？** 例中的用户已经通过 MCVideo 服务认证和授权，客户端已经注册，也已取得这段录像的 URL。客户端向存有录像的服务器发起拉取。请求用主叫的 MCVideo ID 标识发起者，以文件 URL 指定录像，并携带 SDP 提议来协商媒体。服务器检查的是这个客户端是否有权拉取**所请求的录像**，不是仅仅看它有没有注册。[TS 23.281 V16.4.0，表 7.3.2.2.1-1，印刷页 84](https://www.etsi.org/deliver/etsi_ts/123200_123299/123281/16.04.00_60/ts_123281v160400p.pdf#page=85)；[§7.3.2.4.1–2 前提，页 86](https://www.etsi.org/deliver/etsi_ts/123200_123299/123281/16.04.00_60/ts_123281v160400p.pdf#page=87)；[§7.3.2.4.2 步骤 1–2，页 87](https://www.etsi.org/deliver/etsi_ts/123200_123299/123281/16.04.00_60/ts_123281v160400p.pdf#page=88)。

**收到成功应答，能看到什么证据？** 服务器接受请求后，向客户端返回带 SDP 应答的响应。媒体面和传输控制另行建立，之后服务器才向客户端传送录像流。若记录停在成功响应，可以确认请求已被接受，不能据此确认客户端已收到画面、用户已经看过，或本地已保存文件。[§7.3.2.4.2，印刷页 87](https://www.etsi.org/deliver/etsi_ts/123200_123299/123281/16.04.00_60/ts_123281v160400p.pdf#page=88)。

**能播放，不等于能快进或快退。** 快进和快退是接收方远程控制录像流的例子。这次会话能用哪种操作，要看双方的 SDP 协商结果；仅看到正常播放，不能认定这两个操作都可用。[§7.3.2.4.2，印刷页 87](https://www.etsi.org/deliver/etsi_ts/123200_123299/123281/16.04.00_60/ts_123281v160400p.pdf#page=88)。

**谁来结束？** 用户中途停止时，客户端向服务器发拉取完成请求，由服务器确认。服务器也可以按自身的内部条件结束，例如录像已播到文件末尾。完成信息表适用于两个方向：若由服务器发出完成请求，应答便从客户端返回服务器。两个方向的完成请求都必须带主叫的 MCVideo ID 和结束原因；完成应答表只列主叫的 MCVideo ID，不要求回显原因。这里的“主叫”仍是发起拉取的用户，不会因为服务器发出完成请求而改变。如果日志只留下应答表里的主叫 ID，没有收发方向或结束原因，就无法判定哪一方发出了这次完成请求，也不知道为什么停止。若保留了应答的收发方向，则可以反推这次请求的方向：客户端向服务器应答，说明请求来自服务器；服务器向客户端应答则相反。方向只能辨认谁发起这次结束交换。即使确认是服务器发起，也不能仅凭方向断定录像播到了末尾。[§7.3.2.4.2，印刷页 87](https://www.etsi.org/deliver/etsi_ts/123200_123299/123281/16.04.00_60/ts_123281v160400p.pdf#page=88)；[§§7.3.2.2.3–4、表 7.3.2.2.3-1 和 7.3.2.2.4-1，页 84](https://www.etsi.org/deliver/etsi_ts/123200_123299/123281/16.04.00_60/ts_123281v160400p.pdf#page=85)。

若是甲把自己的画面发给乙，查[一对一视频推送](one-to-one-video-push.md)：这是主叫向被叫发送视频的私呼，传输完成后沿用[一对一私呼释放](private-call-release.md)。它不能代替用户从服务器拉取录像时的完成请求与应答。[§7.4.2.3.1，页 93](https://www.etsi.org/deliver/etsi_ts/123200_123299/123281/16.04.00_60/ts_123281v160400p.pdf#page=94)；[§7.4.2.3.3，页 94](https://www.etsi.org/deliver/etsi_ts/123200_123299/123281/16.04.00_60/ts_123281v160400p.pdf#page=95)。

# Release 20

按问题选入口。当前收录两类局部条款：Stage 1 讲在网通话的业务功能，以及在网与离网共用的组呼和带话权私呼同时收发、带话权紧急私呼要求；Stage 3 讲主系统在线配置、配置 GET 的目标与角色、CMC 整份写入与节点写入的区别、CMC 的配置删除目标、外设离线配置、CMS 自发 SIP 失败响应的可选角色头、业务服务器的组织配置订阅及取文、共同初始配置模板与终端 XCAP 寻址、在网初始配置的 TLS 双向认证校验、默认用户档引用与校验、在线 CMS 的用户档维护、伙伴迁移配置和 MCPTT 用户配置档的寻址、部分校验和远程请求权限，位置用户配置的 XCAP 寻址和授权，以及 MCPTT、MCVideo 在网广播 ad hoc 组呼的时长配置。后者不是前一类通话需求的协议实现。

- [MCPTT 通话需求](topics-calls.json)：TS 22.179 V20.0.0。远端触发呼叫与环境监听的区别；环境监听碰到私呼或组呼时的处理；ad hoc 组呼的转发条件和发起者通知；在网组呼何时要建呼确认、到期怎么处理；在网接入优先级与应用层停呼；发话申请结果、接收侧提示与队列；发话结束与单次发话时限；已配置插话的组如何交接话权；多发话者组的并发上限、抢占与申请结果；在网私呼的手动接受、自动确认与收件通知；在网多候选私呼的首应答；同一终端组呼与带话权私呼同时收发的方向与上限；非 3GPP 互通私呼有话权时的抢占；GSM-R 在网语音互通的三项要求；发话接入 KPI 1/2、口到耳 KPI 3 和接收端首尾丢音；进行中组呼的迟入计时与 KPI 4a/4b；话音质量 MOS-LQO 与编解码器支持；带话权紧急私呼的告警、优先级与本人状态；普通电话与 MCPTT 呼叫的互动配置。
- [身份与用户配置](topics-identity.json)：TS 24.484 V20.1.0。查主系统初始配置和默认档的下载条件、认证后订阅，区分初订的直接与代理分支，以及首个 NOTIFY 与取文。CMC 续订时，代理换清单的返回地址和直接续订的鉴权分开查。配置 GET 按整份文档、元素、属性或命名空间绑定分别核 CMC、业务服务器和 CMS。整份配置的创建和更新都用 PUT，另查两种支持要求及节点对照。CMC 配置 DELETE 按实际 Request-URI 查整份文档、元素或属性，和在线用户库删除分开。CMS 自行返回 SIP 失败时，另查可选的 Response-Source 和状态码的区别。外设离线配置另查 CMS/GMS 分工和默认用户档先建条件。业务服务器订阅组织配置时用自己的 PSI，HTTP 取文另核发送方。共同初始配置的管理员模板与终端 XCAP 路径单独收录，可对照 MCPTT 业务 UE 档和用户档。初始档启用 TLS 双向认证而凭据都没有或都填时，分别查 CMS 409 的组合校验。若初始档引用默认用户档，另查 XUI、档案索引与 409 校验。CMS 转换管理员文档、取存用户档和获知库中变更也各有条件。迁入伙伴时查怎样从主侧档选伙伴、办两次业务授权和订阅。MCPTT 用户配置档的 XCAP 路径、409 校验、预选标记及三项远程请求权限也从这里查。位置用户配置的业务档引用、共用授权和文件索引另有入口。在网广播 ad hoc 组呼的挂起时长归 MCPTT 和 MCVideo 的业务配置。

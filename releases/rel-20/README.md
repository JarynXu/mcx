# Release 20

按问题选入口。当前收录两类局部条款：Stage 1 讲在网通话的业务功能和适用要求；Stage 3 讲主系统在线配置与取文、伙伴迁移配置和 MCPTT 用户配置档的寻址、部分校验和远程请求权限，位置用户配置的 XCAP 寻址和授权，以及 MCPTT、MCVideo 在网广播 ad hoc 组呼的时长配置。后者不是前一类通话需求的协议实现。

- [MCPTT 通话需求](topics-calls.json)：TS 22.179 V20.0.0。远端触发呼叫与环境监听的区别；环境监听碰到私呼或组呼时的处理；ad hoc 组呼的转发条件和发起者通知；非 3GPP 互通私呼有话权时的抢占；GSM-R 在网语音互通的三项要求。
- [身份与用户配置](topics-identity.json)：TS 24.484 V20.1.0。查主系统初始配置和默认档的下载条件、认证后订阅，以及如何区分首个 NOTIFY 与取文；或查迁入伙伴时怎样从主侧档选伙伴、办两次业务授权和订阅。MCPTT 用户配置档的 XCAP 路径、409 校验、预选标记及三项远程请求权限也从这里查。位置用户配置的业务档引用、共用授权和文件索引另有入口。在网广播 ad hoc 组呼的挂起时长归 MCPTT 和 MCVideo 的业务配置。

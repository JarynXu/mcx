# Release 20 覆盖范围

已收录 TS 22.179 V20.0.0 的两处 MCPTT 通话需求（Stage 1），以及 TS 24.484 V20.1.0 的主系统在线配置、伙伴迁移配置、CMC 配置订阅及取文、MCPTT 用户配置档寻址与部分校验条款（Stage 3）。两者按各自范围阅读；未覆盖完整规范、其他规范或整个 Release，未据此验证实现。

## MCPTT 环境监听与 ad hoc 组呼转发

可区分另一呼叫打断环境监听时的结束、暂停后恢复与有条件并行；可查 ad hoc 组呼转发的配置权限、四类触发和发起者成功通知。

TS 22.179 V20.0.0 的 Stage 1 通话需求。环境监听看被监听用户实际发送或接收；转发超时或拒绝仅列手动开始模式。

未收录这些功能的 Stage 2、Stage 3 或实际设备表现，不确定 SIP 映射、媒体状态机或目标已入会；不代表完整 Rel-20 覆盖。

## 伙伴系统迁移时的身份与用户配置

区分主系统给的接入配置档、伙伴侧订阅的配置档、IdMS 的 HTTPS 地址和 CMS 订阅代理的 SIP 标识；判断变更通知能证明哪一步。

TS 24.484 V20.1.0 的伙伴迁移在线配置；代理初始订阅、MCPTT 伙伴条目结构和 schema 只用于辨认对应分支。

不覆盖各业务迁移授权、伙伴认证的完整消息，未验证 TS 24.481 组文档取回、业务采用新配置或实际互通；没有裁定 MCPTT XML 层级差异在网络上的编码。

## 主 MC 系统在线配置

可区分初始配置和默认用户配置档的更新条件、认证前默认身份和认证所得身份、认证后订阅和本地副本更新。

TS 24.484 V20.1.0 §4.2.2.1.1（含图和注），只说明主 MC 系统的在线配置。

不包括认证报文、首次无本地版本时的下载方案、业务采用新配置的时点或设备实测。

## MCPTT 用户配置档寻址及校验

可按已认证的 MCPTT ID 与配置档索引定位文档，区分 XUI、文件名及预选标记导致的 409；可判断唯一档未带预选标记的含义。

TS 24.484 V20.1.0 §8.3.1、§8.3.1A、§8.3.2 中与 MCPTT 用户配置档寻址、命名、XUI 和预选限制有关的条款。

不覆盖 §8.3 的全部校验或编解码要求，不规定身份规范化、容错文件名或预选档的原子切换，也不把本版文字归因于某一条 CR 改动。

## MCPTT 终端配置订阅和取文

区分主系统 CMC 多文档代理订阅的 SIP 应答、首通知的 XCAP Diff 元数据、确实收到的 HTTP 配置正文和本地副本。

TS 24.484 V20.1.0 的 CMC 代理初始订阅、CMS 对应入站分支和 CMC 取文；首通知及后续三份取文只对照资料性附录 A.2.2。

不展开各类重新订阅、身份隐藏、业务服务器的订阅、其他 XCAP Diff 形态或组文档取回。示例不证明某台终端保存或应用了配置。

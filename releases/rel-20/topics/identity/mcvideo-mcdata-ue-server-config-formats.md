# MCVideo、MCData 配置下载：终端和业务服务器各对应哪些文档？

**在线终端有三种业务文档的格式指针。业务服务器的对应条款只列业务配置文档的格式。**例如，下载到 MCVideo UE 的业务配置与下载到 MCVideo 服务器的业务配置，都按 §9.4 找格式；不能凭同一格式认定是同一份档案。

依据：3GPP TS 24.484 V20.1.0（Release 20，Stage 3）§4.2.2.3、§4.2.2.4、§4.3.3、§4.3.4。

| 接收方 | UE 配置文档 | 用户配置档文档 | 业务配置文档 |
| --- | --- | --- | --- |
| MCVideo UE 在线下载（§4.2.2.3） | §9.2 | §9.3 | §9.4 |
| MCVideo 业务服务器（§4.3.3） | 本节未列 | 本节未列 | §9.4 |
| MCData UE 在线下载（§4.2.2.4） | §10.2 | §10.3 | §10.4 |
| MCData 业务服务器（§4.3.4） | 本节未列 | 本节未列 | §10.4 |

## 格式相同，不等于收到同一份文档

先按业务和接收角色选一行，再按文档类型找格式。§9.4 对 MCVideo 的两种接收角色适用，§10.4 对 MCData 的两种接收角色适用。这四条不决定两端所取文档的实例、组织、实际 URI、内容、版本或传输是否相同，也不把业务服务器、CMS 和 UE 的角色合并。服务器两节未列向服务器下载 UE 配置或用户档，不能把在线 UE 的另两类格式套给服务器，也不能据未列认定服务器在其他流程不能访问它们。

## 问取文条件，换到对应接收方的流程

- **UE 在线取用：**§4.2.1 按每个已启用业务，经初始配置 MO 指定的 CMS URI 取得相应文档；位置用户配置也列在该流程，MCS 组文档另经 GMS URI。这不是上表的额外格式列。主系统认证、订阅和更新副本看[主系统在线配置](primary-ue-online-configuration.md)，迁入伙伴系统另看[伙伴迁移](partner-migration-profile.md)。不因这些相邻流程给 §4.2.2.3/.4 的格式规定额加主系统限定或下载触发条件。
- **业务服务器取用：**§4.3.1 说的是业务服务器从 CMS 取得适用组织的业务配置。查[服务器订阅和 HTTP 取文](mcs-server-service-config.md)；该流程的组织条件、订阅、通知、实际取文不由上表的格式编号代替。旧例中的 MCPTT global URI 不能直接当成 Video 或 Data 的具体地址。
- **其他对象：**谁可以配置文档，看[MCVideo、MCData 管理员](mcvideo-mcdata-admin-configuration.md)；外设给终端配的是[离线管理对象（MO）](offline-ue-configuration.md)，不套在线配置文档格式。知道格式、收到通知或看到取文请求，都不能单独证实这次下载或应用完成。

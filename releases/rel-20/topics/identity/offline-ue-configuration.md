# MCS 终端离线配置：哪台设备配什么，默认用户档要先建吗？

TS 24.484 V20.1.0，Release 20。这里的离线配置指 **UE 没有连接任何 MCS 网络，外部设备仍能通过 IP 连接 UE 并为它配置**。笔记本是例子，USB、WLAN、蓝牙只是承载这条 IP 连接的例子。UE 断网运行不等于它正在被离线配置；UE 经中继仍连接着 MCS 网络，属于在网运行。（§3.1）

## 外设上的两个角色

| 角色 | 给 UE 配置什么 |
| --- | --- |
| 离线配置管理服务器（CMS） | MCS UE 初始配置 MO，以及适用的 UE 配置 MO、用户配置档 MO、业务配置 MO。 |
| 离线组管理服务器（GMS） | MCS 组 MO。 |

§4.2.1 项 2(a) 和 2(b) 是同一条离线路径的两个角色，不是二选一。两者都在外部设备上；不规定两台设备，也不把组 MO 归给离线 CMS。在线是另一条路径：UE 用初始 MO 给出的 CMS 和 GMS URI 取得相应文档；在线分支还列位置用户配置文档，不能拿在线列表当本条的离线 MO 清单。详见[主系统在线配置](primary-ue-online-configuration.md)。

## 管理员提供哪个用户，默认档配在哪儿？

离线 CMS 需支持 MCS 管理员提供**这台 UE 要为之配置的 MCS 用户的一项或多项身份**，好把对应 MCPTT 用户的配置放进 MO。相邻编辑注将身份元素如何寻址留待研究，不能拿这条代替在线认证、规定身份格式或推定认证成功。（§4.2.3.1）

如果 MCPTT 业务管理员把 `DefaultUserProfile` 放入 MCS UE 初始配置 MO，该节的注说，**先在离线 CMS 上建至少一份用户配置档 MO**。这同一份档案须含默认引用中给出的两个值：`MCPTTUserID` 和 `UserProfileIndex`。只有用户 ID 匹配不够；两个值分别能在不同档里找到也不够。初始 MO 未设这个引用，不触发该注的先建条件，也不能据此断定用户档一概不需要。不要把[在线 XCAP 初始文档的默认档引用与校验](default-profile-reference-xcap.md)的字段名或 HTTP 409 套到这里。（§4.2.3.1 注）

## 可核到的接口边界

§1 把 CSC-11、CSC-12 列为离线配置的参考点。§4.2.1 没有规定 CMS 的发现方式或在线失败后的自动离线切换；它把发现机制留给配置 MO 所用的协议。§4.4 的注不展开离线 CMS/GMS 功能，不能把在线 CMS 的读库、取文或订阅规则搬过来；这不否定上表列出的角色。

对 MCPTT UE，§4.2.3.1/.2 将初始、组及 MCPTT 的 UE/用户档/业务 MO 格式指向 TS 24.483；主系统在线的组文档格式另指 TS 24.481（§4.2.2.1.1）。这里只核这些指向，不核目标格式、参考点与角色的逐一绑定或使用哪种设备管理协议。外设接通 IP 或建好默认档，也不证明终端已收到并采用了配置。

## MCVideo、MCData 的离线管理对象查哪份规范？

| TS 24.484 V20.1.0 条款 | 条款列的管理对象（MO） | 六句在两个小节中所写的接收方 | 格式出处 |
| --- | --- | --- | --- |
| §4.2.3.3 MCVideo | MCVideo UE 配置 MO、MCVideo 用户配置档 MO、MCVideo 业务配置 MO | 三句都是 MCPTT UE | TS 24.483 [4] |
| §4.2.3.4 MCData | MCData UE 配置 MO、MCData 用户配置档 MO、MCData 业务配置 MO | 三句都是 MCPTT UE | TS 24.483 [4] |

**对象的业务名称和句中的接收方要分开读。**两个小节按标题列 MCVideo 或 MCData 的 MO，但说的是离线配置时下载到 **MCPTT UE**。查对象格式仍按表中指向；不能把接收方改写成 MCVideo UE 或 MCData UE，也不能从这两段判定设备只能是 MCPTT、某个终端支持离线配置、或这次下载已发生。这里照录原文称谓，不判断是否应勘误。

TS 24.483 [4] 没标具体版次；§2 的规则是查同一 Release 的最新版本。这里仅核格式指针，不核所引版本或正文，不补 MO 字段、传输、设备管理过程、CSC-11/12 对应关系或业务生效。外设 CMS 和 GMS 的分工仍按上面的 §4.2.1。要查[在线下载到 MCVideo 或 MCData UE 的配置文档](mcvideo-mcdata-ue-server-config-formats.md)，看 §4.2.2.3/.4 指的第 9/10 章；不要用它们替代这些离线 MO 的格式，或反过来改写离线小节的接收方。

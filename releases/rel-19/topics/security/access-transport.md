# 接入安全：HTTP-1 与 SIP-1 不共用一条认证规则

依据 ETSI 发布的 3GPP TS33.180 V19.4.0 §6.1.1–6.1.2、§6.2.1–6.2.2。以下只解释指定参考点，不代替应用用户授权。

## HTTP-1

终端 HTTP 客户端与 HTTP 服务器端点必须支持 TLS。HTTP-1 必须执行以下三种认证机制之一：服务器证书单向认证、双向证书认证或双向 PSK 认证，不应一概要求客户端证书。证书和 TLS 的具体 profile 另依 TS33.310；PKI 结构不在本规范范围内。

## SIP 核心接入与 SIP-1

IMS AKA 的适用不取决于 SIP 核心是否符合 TS23.228。非3GPP接入可考虑 TS33.203 附录 N/O 的其他认证机制，此类用例按 NDS/IP 保护接口，已有其他保护（例如物理安全）除外。仅非3GPP、且无 UICC 的终端还可考虑 TS33.203 §9 的 IMC。SIP-1 信令的保密性和完整性采用 TS33.203 的 Gm 安全机制。

## 尚不能据此配置什么

本文未核 TS33.203、33.210、33.310 的具体 profile，不能给出完整密码套件或部署参数；也未覆盖用户令牌、跨域授权或媒体密钥。不声称与 V19.5.0 等同。

# 访问控制：配置停用与终端禁用

适用：Release 19，TS 22.280 V19.7.0，Stage 1 在网要求。已核对下列条款，不是协议实现说明。

被删除或暂停的用户配置不能再用于访问服务；这不等于永久禁用整台 UE（§6.13.4 R-001/002）。

管理员或获授权用户可远程暂时禁用 UE；服务还须提供重新启用暂时禁用 UE 的机制，但这里未指定重新启用的传输方式。暂时禁用期间的有限访问依组织策略（R-003/005/006）。永久禁用则要求 UE 删除本机所有 MCX 服务用户配置，并失去 MCX 服务访问（R-007/008/009）。

## 使用边界

本页不规定命令编码、永久禁用后的恢复流程，也不把删除用户配置解释为存储介质的安全擦除。

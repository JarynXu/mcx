# 紧急告警、状态与组通信

适用：Rel19，TS22.280 V19.7.0，Stage 1 要求。

用户启动紧急告警能力，会进入 Emergency State 并由 UE 发送告警（§5.6.2.4.1 R-001，p20）。是否同时自动触发紧急组通信由管理员配置（R-013，p21）；告警不等于已经建立组通信。

UE 保留紧急状态直到取消；该状态未在 UE 取消前，用户的组通信或私有通信发送应为对应的紧急通信（R-006/007，p21），不能在发完一次告警后自行清除。

UE 本地取消紧急状态的入口仅给该 UE 的授权用户；告警取消也须支持授权 MCX 用户，取消通知送往取消消息所标识组的全部已归属成员（§5.6.2.4.2 R-001–003，p21）。

这是要求层边界，不替代组内 In-progress Emergency 的独立状态机、远端取消协议或认证流程。[来源](../../sources.json) · [结构化条件](alert-state.json)

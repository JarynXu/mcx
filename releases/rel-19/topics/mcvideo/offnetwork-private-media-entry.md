# 离网私呼接通：双方状态和媒体许可缺口

## 适用范围

- 固定TS24.281 V19.3.0 §10.3，两个已确定用户之间普通离网私呼，选择自动应答路径；不处理发现邻居、组呼加入、手动应答、video pull、紧急、网关或在网SIP/PF/CF流程。
- 目标MCVideo ID和所需离网传输配置已经具备，具体发现、地址解析及ProSe承载取得未核。每个私呼控制状态机以MCVideo user ID为粒度，同时私呼数受配置MaxCallNc10限制；不创造数值或超限响应。
- P0无私呼控制实体；P1非进行中且忽略同call id；P2等呼叫响应；P3等释放响应；P4正在通话；P5为pending。必须按claim的本地角色、状态、消息及call-id条件执行，不能把一端状态当两端同时成立。
- 普通媒体与transmission control只保留24.281声明的接口。TS24.581 V19.2.0的离网媒体过程未核；TS24.379、24.483、33.180及RFC细节未核，不声称已闭合发送/接收许可、首帧、完整互通或安全算法。

## 发起端收到接受后的媒体入口

适用条件：发起端P2收到回应其SETUP REQUEST且call identifier相同的PRIVATE CALL ACCEPT。

发起端存SDP answer并发ACCEPT ACK，停止运行中的TFP1/TFP2，按answer建立媒体；随后启动transmission control、TFP5并进P4。原文把该端角色写为terminating transmission participant，并指向24.581的clause a.b；保留字面，不自行改角色或选择某个在网状态。P4/媒体建立不证明已获具体流的发送或接收许可，更不证明首帧显示。

- 未取得24.581离网原文，不能给出grant、排队、接收请求、首帧确认的算法。
- 不把ACCEPT ACK当SIP ACK，也不把SDP建立义务写成已实际成功传输。

依据：3GPP TS24.281 V19.3.0 §10.3.2.4.2.8，印刷页 358、359。

## 终接端的两种后续触发

适用条件：自动应答终接端已按接受分支进入P5；收到发起用户的PRIVATE CALL ACCEPT ACK或RTP媒体。

实际处理者是自动接收端P5。该接收端须停TFP4，按本段引用启动transmission control；step2字面称originating MCVideo client并指向24.581 clause a.b，保留该角色称谓差异，不改成终接。随后启动TFP5并进P4。这两种触发是替代关系：ACK路径无需先证明RTP到达；RTP路径只表明相应媒体接收事件，不等于完成解码、展示或应用验收。

- 本段仍引用24.581 clause a.b；没有完整媒体资格判据。
- 本入口未重述call-id相等检查，不自行加成原文强制字段校验；完整消息分派仍未核。

依据：3GPP TS24.281 V19.3.0 §10.3.2.4.3.4，印刷页 362。

## 两端建立超时各自处理

适用条件：分别观察自动模式发起端P2的TFP1/CFP1，或接受后的终接端P5的TFP4/CFP4。

普通计时到期重传各自SETUP REQUEST或ACCEPT并增加相应计数、重启计时器、保留等待状态；当发起端TFP1到期且CFP1等于上限并为自动模式时，启动TFP7并进P1；终接端TFP4到期且CFP4等于上限时，同样启动TFP7并进P1。这是不同端点的有限失败出口，不是SIP超时响应。

- 原文一般重传与达上限专节并列，未在一般入口写低于上限；不提供自行裁定的重叠事件执行优先级。
- 不造计时秒数/重传上限，也不从进P1推定全部媒体资源已清，尤其终接先建立媒体后的失败段未列清理步骤。

依据：3GPP TS24.281 V19.3.0 §10.3.2.4.2.2;10.3.2.4.2.4;10.3.2.4.3.3;10.3.2.4.3.5，印刷页 357、358、361、362。

## 原文差异与未核边界

§10.3.2.4.2.8 step7，印刷页 359：发起端接收ACCEPT后的媒体调用字面为terminating transmission participant且引用clause a.b；不自行修正角色或引用。

§10.3.2.4.3.4 step2，印刷页 362：实际入口为自动接收端P5，媒体调用字面却称originating MCVideo client并引用clause a.b；并列保留实际处理者及源文角色，不裁决。

§10.3.2.4.2.2/.4;10.3.2.4.3.3/.5;10.3.2.4.5.2/.3，印刷页 357、358、361、362、366、367：一般超时重传与计数上限出口并列，未写完整优先级，不裁决同时满足的执行调度。

## 证据边界

- 仅已确定用户间自动应答的有限离网信令路径，不是可直接实现的完整协议或媒体指南。

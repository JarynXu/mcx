# 组文档寻址与成员表权限

Release 19；TS 24.481 V19.3.0。下列两条已对照[规范原文](https://www.etsi.org/deliver/etsi_ts/124400_124499/124481/19.03.00_60/ts_124481v190300p.pdf#page=65)核对，不代表完整授权实现已验证。

## 按组 ID 访问不会增加权限

按组 ID 寻址的文档沿用其关联 users-tree 文档的管理授权；全局路径不是公开访问许可。依据：§7.2.12.2，正文第 65 页。

## 成员身份不自动允许读取全表

在“组成员读取成员表”这一授权分支，还须匹配文档中的 rule：conditions 为真或缺省，且 actions 含 on-network-allow-getting-member-list。依据：§7.2.12.1，正文第 64 页。

该分支不概括服务器、文档所有者或本人 entry 等其他授权路径。本文不提供完整权限算法、身份认证或 XCAP 实现。

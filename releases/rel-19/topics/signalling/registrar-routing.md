# SIP 路由：寻找注册器与保存用户绑定

适用：Release 19，TS23.280 **V19.9.0**，Stage2。此版本独立核对，不替代库内其他版本。

注册器寻找功能（registrar finder）负责根据相应提供方的 SIP 数据库定位服务注册器，也可利用运营商拓扑或可用性信息。是否需要它取决于部署，只有一个注册器时可以不设置（§7.4.3.1.3.3）。

注册器保存用户身份与 SIP 注册位置/可达绑定的关联（不是 LMS 地理位置报告）、通知注册状态，并可承担应用服务选择（§7.4.3.1.3.4）。这些是逻辑职责，不要求每种功能独占一台机器（§7.4.1）。

应用到分布式设计时，应分别讨论“用户绑定在哪”和“消息由谁处理”。这是设计问题定位，不是本条款给出的黏性算法：它没有证明 Call-ID 哈希、某个工作进程常驻、会话复制或故障转移方案符合标准；对话内路由仍须另核 SIP 协议。

# 功能别名：共享与接管

适用：Rel19，TS22.280 V19.7.0 的 Stage 1 要求；不是接口实现说明。

管理员对每个别名选择：允许多人同时激活并设置上限、允许授权用户接管、或两者均不允许。共享与接管不能同时配置（§5.9a.1；§5.9a.2 R-5.9a-005，p22–23）。

用户以 MCX User ID 登录后再激活别名（§5.9a.1）。当用户尝试激活已被其他用户使用的别名时，共享模式未满额则激活并通知其他使用者；不允许共享或已满额则告知已占用，满额的授权用户请求也须拒绝（R-006/007/008a，p23）。

尝试激活另一用户已使用的别名，且允许接管、未配置共享、请求者获授权时，系统提供接管选项；实际接管后激活给新用户，并通知原用户已停用（R-008/009，p23）。这不是无条件自动抢占。

# 离网SDS通知：原消息关联与独立重发

## 适用范围

- 固定 TS24.282 V19.7.0，Stage 3，§9.3 离网 standalone SDS 信令控制面；不套用在网 SIP/MSRP、MBMS/MBS、FD 或 SDS session 过程。
- 各结论仅在所列客户端角色与事件成立时使用；发送前授权、安全上下文、承载及地址配置应满足各自规范。本页不提供完整编码、安全或发现实现。
- 组发送请求在 AllowedSDS=false 时须拒绝并停止余下发送程序；其余初始发送参数和安全处理仍按§9.3.2.2，不以重试结论跳过。

## 原消息关联与通知时间

适用条件：接收客户端按请求和显示/处理事件进入对应离网通知生成程序，相关原消息状态已保存。

通知须采用已保存的Conversation ID和Message ID，发送者字段是本客户端用户ID。DELIVERED使用接收时保存的通知时间；READ或合并通知先更新为当前UTC时间。应用ID或扩展应用ID在这些通知程序中为may，不将其改为无条件必填。

- 仅保存原消息关联，不证明通知已到达原发送者。§12.3.2目标称stored notification target，§12.3.3/.4称stored sender，未给出后者在本链的显式赋值；不据此生成无歧义完整路由实现。

依据：3GPP TS24.282 V19.7.0 §9.3.2.4 steps1–7;12.3.2–12.3.4，印刷页 263、321、322。

## 通知独立重发

适用条件：通知发送客户端已发离网通知，随后TFS2到期。

首次发通知后须将CFS2置1并启动TFS2；到期须按已存标识、通知时间和通知类型重新生成发送，CFS2加1，未达上限才再启动。TFS2默认40毫秒、CFS2默认上限5，均可配置，与消息的TFS1/CFS1分别维护。

- 达到上限只结束这轮通知重发计时，不是通知接收确认，也不证明全部组成员已读。
- §12.3.5同样使用stored sender称谓；本页保留上述状态命名缺口。未核通知接收端去重、ACK、全组聚合或并发通知状态隔离。

依据：3GPP TS24.282 V19.7.0 §12.3.2 steps4–5;12.3.3 steps5–6;12.3.4 steps5–6;12.3.5;F.3.1;G.3.1，印刷页 321、322、323、641、643。

## 证据边界

- 只核本页问题，不等于完整离网协议或所有结束情形已覆盖。

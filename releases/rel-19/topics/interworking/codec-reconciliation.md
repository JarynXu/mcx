# 互通组更换语音编解码：许可、应答与媒体怎么分？

适用版本：TS 23.283 V19.5.0，Rel‑19，Stage 2。

**IWF 转码和互通组更换共同编解码，是两件事。** §10.7.2 的转码做法允许 MCPTT 和 LMR 各用各的语音编解码，IWF 在两侧之间转换语音格式。本规范不规定 LMR 一侧用哪种。§10.7.3 描述另一种做法：互通组可配置为共用 LMR 语音编解码，让两侧组员的语音端到端传送而无需转码。配置或编解码能力只能说明可采用哪种做法，不能证明本次已转码、已开启端到端加密或已收到语音。

## 何时查更换流程？

§10.7.3.1 列出四个前提：两侧已有成员归属到该组；已为 MCPTT 组员协商一种允许使用的 LMR 语音编解码；MCPTT 组成员支持请求的第二种 LMR 语音编解码；LMR 系统需要换用另一种。已协商的允许项和此次请求项要分开。若 IWF **不支持转码**，且 MCPTT 客户端**也不支持这次请求的 LMR 编解码**，NOTE 1 把这个例外排在规范范围外，没规定怎样回退。只满足其中一项，不是该条排除的组合，也不能判这次更换能成功。

[§10.7.2 及 §10.7.3.1 前提 1–4、NOTE 1，印刷页 145–146（PDF 第 146–147 页）](https://www.etsi.org/deliver/etsi_ts/123200_123299/123283/19.05.00_60/ts_123283v190500p.pdf#page=146)。

## 哪一笔在问，哪一笔在答？

| 原文步骤 | 如何区分 |
| --- | --- |
| **1．IWF → MCPTT server** | IWF 代表 LMR 系统发更换请求。表 10.7.1.1‑1 的 **MCPTT group ID** 和 **Codec type** 均必选，分别是请求更换的组和请求的编解码。 |
| **2．server 查组许可** | 图称 *Authorization check*；正文说查**请求项对该组是否允许**。不把既有允许项、成员支持或已发请求当成本次核查通过。 |
| **3/4．server ↔ MCPTT 客户端** | server 向**所有已归属的 MCPTT 客户端**发协商请求；图只画一个，步骤 4 是该客户端回给 server 的对新项的接受。客户端发出步骤 4 是它表态接受；server 是否收到，要看 server 一端。只见某一端确认，不等于其他端都接受。 |
| **5．MCPTT server → IWF** | 表 10.7.1.2‑1 的 **MCPTT group ID** 和 **Result** 均必选。Result 是所请求更换的成功或失败，不是客户端的步骤 4，应答表不列返回编解码的字段。 |

查任一笔的字段，可以只读对应表。要把步骤 5 的结果归给步骤 1，须确认是**同一次更换**；比如同一个组先后请求 B 和 C，单凭组 ID 和 Success 不能判断是哪次。只见 server 发出步骤 5，不证明 IWF 实收；图把 4 画在 5 前，不能据此确定要不要等全员、怎样汇总、何时超时或如何处理失败。两张表用在 IWF 一侧的步骤 1/5，不补客户端 3/4 的字段。

[§10.7.1.1/.2，表 10.7.1.1‑1、10.7.1.2‑1，印刷页 145（PDF 第 146 页）](https://www.etsi.org/deliver/etsi_ts/123200_123299/123283/19.05.00_60/ts_123283v190500p.pdf#page=146)；[§10.7.3.1 图 10.7.3.1‑1、步骤 1–5，印刷页 146（PDF 第 147 页）](https://www.etsi.org/deliver/etsi_ts/123200_123299/123283/19.05.00_60/ts_123283v190500p.pdf#page=147)。

## 成功应答之后，媒体什么时候换？

成功更换流程的步骤 6 写组内**后续媒体传输用新编解码**。NOTE 2 把发送方**首次使用新编解码的时刻**留在规范范围外。要说本次哪端何时真的用了新编解码，要看该端实际媒体，不能用步骤 4、5 或其时间戳代替。不能从这张图推算同步切换点，也不能用它补 SIP/SDP、RTP 标识或播放结果。

[§10.7.3.1 步骤 6 与 NOTE 2，印刷页 146（PDF 第 147 页）](https://www.etsi.org/deliver/etsi_ts/123200_123299/123283/19.05.00_60/ts_123283v190500p.pdf#page=147)。

如果实际在查已建会话内的加密语音如何转码，读[加密语音转码](encrypted-transcoding.md)。那个流程的密钥和方向条件不加到本页的编解码更换里。

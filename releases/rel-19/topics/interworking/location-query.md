# 互通位置：按需查询与通知

TS23.283 V19.5.0，Release 19，Stage 2。LMS是位置管理服务器，LMC是位置管理客户端；IWF按需转换MC与LMR身份。

## MC服务服务器或LMC请求LMR用户位置

LMS依据请求信息及配置检查许可、确定LMR目标，再向IWF请求。IWF可另作授权检查，取得与请求中MC身份对应的LMR位置，报告经LMS返给请求方。 [§10.11.4.2.1.1](https://www.etsi.org/deliver/etsi_ts/123200_123299/123283/19.05.00_60/ts_123283v190500p.pdf)

## IWF需要MC用户位置

IWF确定MC目标后请求LMS；LMS授权、取得位置并返给IWF。图称返回消息为response，正文称report并引用§10.11.4.1.1，不能据此杜撰两个协议消息。 [§10.11.4.2.1.2](https://www.etsi.org/deliver/etsi_ts/123200_123299/123283/19.05.00_60/ts_123283v190500p.pdf)

## LMS或IWF判断有可通知的位置

双方均可向另一方发送位置通知。该过程未要求每次通知重新测量，不能单凭通知断言位置新鲜。 [§10.11.4.2.2.1–2](https://www.etsi.org/deliver/etsi_ts/123200_123299/123283/19.05.00_60/ts_123283v190500p.pdf)

## 按需请求、位置报告和事件通知各查哪张表？

先判断这条是**索取位置、回报按需请求，还是决定有位置可通知后的发送**。TS 23.283 V19.5.0 §10.11.4.1 为 IWF 与 LMS 的每种信息流各指向一张 TS 23.280 [5] 的表。下列三种信息流各列 **LMS→IWF 和 IWF→LMS**；方向相同也可以是不同消息。查这个引用不需要抓包。

| 这条消息 | TS 23.283 入口 | 转引 TS 23.280 |
| --- | --- | --- |
| IWF 位置报告（report） | §10.11.4.1.1 | 表 **10.9.2.2-4** |
| IWF 位置请求（request） | §10.11.4.1.2 | 表 **10.9.2.3-4** |
| IWF 位置通知（notification） | §10.11.4.1.5 | 表 **10.9.2.7-3** |

IWF 发起按需请求时，§10.11.4.2.1.2 图的第 6 步写 response，正文写 report 并指回 .4.1.1，按正文的回指找报告表，不另造第二条应答。事件通知另走 .4.1.5；收到通知不证明这次按需请求已得到结果、已建立某项订阅或重新测量。

这里只核对**表号和信息流**，依赖表的字段、必选项和载荷未核。§2 的 [5] 不指定 TS 23.280 版次；按该节规则，非指定版本的 3GPP 引用用同一 Release 的最新版，不能从本页认定某个 V19.x 表体已复核。§10.11.4 的 NOTE 不规定 MC 与 IWF 的位置消息如何使用特定 LMR 技术；§10.11.4.2 的 NOTE 另外排除伙伴系统限制位置报告和追踪的配置机制。两者不取消各自流程里的许可检查。

[§2 [5]，印刷页 11](https://www.etsi.org/deliver/etsi_ts/123200_123299/123283/19.05.00_60/ts_123283v190500p.pdf#page=12)；[§10.11.4 NOTE、§10.11.4.1.1–.2，印刷页 154](https://www.etsi.org/deliver/etsi_ts/123200_123299/123283/19.05.00_60/ts_123283v190500p.pdf#page=155)；[§10.11.4.1.5、§10.11.4.2 NOTE，印刷页 155](https://www.etsi.org/deliver/etsi_ts/123200_123299/123283/19.05.00_60/ts_123283v190500p.pdf#page=156)；[图 10.11.4.2.1.2-1 和步骤 6，印刷页 157](https://www.etsi.org/deliver/etsi_ts/123200_123299/123283/19.05.00_60/ts_123283v190500p.pdf#page=158)。

## 使用边界

§10.11.4.1的信息字段转引TS23.280，本页未核验这些字段或Stage3编码。

伙伴系统位置限制的配置机制不在§10.11.4.2范围；请求机会不等于无条件授权，也不保证获取新测量。

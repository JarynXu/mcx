# IWF 组呼请求：身份与隐式话权

适用：Rel19，TS23.283 V19.5.0 §10.3.2.2 表10.3.2.2-1（p35），IWF-1 上 IWF 与 MCPTT server 间的 Stage 2 信息流（接口范围见§10.3.2.1）。

该请求必含主叫 MCPTT ID、互通组 ID 和 SDP offer。功能别名、隐式话权请求、广播指示及位置列为可选；可选项仍受各自条件约束。

若组呼从 LMR 发起且 LMR 未提供主叫身份，MCPTT ID 可用 IWF 为 LMR 用户预留的 ID（注1）。因此该值不一定证明主叫终端提供了可辨识的个人身份。

隐式话权请求仅在发起客户端请求话权时才包含（注2）；不能因正在建组呼就默认附带。

这不是完整建呼状态机，不给出 SIP 编码、应答/失败处理或话权授予结果。[来源](../../sources.json) · [结构化条件](group-call-request.json) · [IWF 身份模型](scope.md)

# 位置订阅：动态组目标、通知与取消

适用：单 MC 系统、TS23.280 V19.9.0、Stage2。独立版本核验，不升级 V19.10.1 摘要。

订阅请求可指定 MC service ID 或组 ID。LMS 检查 LMC 请求方的授权；本订阅流程对隐式可信的 MC 服务服务器无需作该检查。以组为目标时，LMS 获取组归属动态数据；组动态数据订阅响应成功后，随归属变化更新目标成员，并在需要时调整上报配置（§10.9.3.5）。位置订阅响应携带订阅状态，不能仅凭请求已发送认定成功。

通知的前提是已订阅且接收权限已核验。配置触发后发送最新位置；按组订阅的 LMC 只接收当前归属成员的位置。MC 服务服务器不接收可选 UE label（§10.9.3.6.1）。

取消订阅需要授权检查。用户已掌握目标 MC service ID 及其位置订阅；组取消还要取消组动态数据订阅、删除对应归属成员列表，并取消同一授权用户或服务器面向相同目标的关联触发（§10.9.3.7）。取消响应携带取消状态，不能仅凭请求已发送认定完成。也不能由此推断其他请求者的所有采集都停止。

此处不定义“空配置”在线路上如何编码，也不补造取消消息字段集合。

# 位置报告与组目标

已核所列同版官方条款，并通过独立复核与有限问题验证。Release：19。来源：TS 23.280 V19.10.1。核查范围及限制见[来源清单](../../sources.json)。

## 谁在报告，谁在接收

LMC（位置管理客户端）向 LMS（位置管理服务器）提供位置。LMS 汇总面向同一目标的报告触发请求。某位订阅用户取消订阅后，停止的是向该用户交付报告；不能据此关闭目标用户向其他接收者的全部报告。

依据：§10.9.1，印刷页186。本文不规定完整订阅 API、鉴权实现或并发控制。

## 报告不一定是经纬度加精度

报告的位置数据应伴随测量时间，准确度可选；所列位置数据至少提供一项，不能假定每次都有经纬度。收到通知也不等于刚执行了新测量，应结合位置数据的测量时间判断。

依据：§10.9.2.2 各报告表及 §10.9.3.6.1。这里不推导应用可接受的时效阈值。

## 组目标随归属变化

本段限单一 MC 系统；LMS 已订阅组动态数据，请求者已订阅且获准请求目标的位置。以组为目标设置报告触发时，LMS 使用当前已归属成员及其后续变化，而不是一次读取静态成员名单后永久沿用。解除归属后，相应的组报告触发应取消。

依据：§10.9.3.3，印刷页209–210。组事件通知也限当前已归属成员，见 §10.9.3.6.1。跨系统组目标不在本页范围。

## UE label 有接收方向限制

在规定的非空配置条件下，发往客户端及跨 LMS 的相关消息携带 UE label；发给 MC service server 的位置消息不包含该标签。不能从一个方向的可选字段表复制出所有方向都必带的编码规则。

依据：§10.9.2.2、§10.9.3.6.1。具体消息字段仍需对应协议阶段的规范支持。

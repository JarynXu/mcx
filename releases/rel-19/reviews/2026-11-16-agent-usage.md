# 首批 Agent 使用检查

对象：位置报告和触发覆盖两篇候选。测试者带有既有任务上下文，因此这不是盲测，也不是标准原文复核。

测试者沿入口读取 6 个文件，回答了订阅取消范围、覆盖期间新请求的恢复，以及 Rel17 复用和通知时效三个问题。回答保留了接收者边界、保存配置的更新规则及版本限制。没有加载整库，也没有把候选说成正式。

检查暴露了两个扩容问题，已修改：
- 主题索引原先同时包含全部 claim。现在索引只负责定位，结构化知识分到各主题旁的 JSON 文件，按需读取。
- 触发覆盖的单条记录未显式继承单系统和授权条件。现在每个主题记录给出 common_conditions，入口明确逐条继承并叠加本条 conditions。

仍未闭合：来源只有版本目录和条款定位，未重新核验标准原文；本次使用检查不能替代该工作，也不作为候选晋级依据。
